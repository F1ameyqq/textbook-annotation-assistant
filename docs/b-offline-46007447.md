## 输入与依赖

Python 3.11+；基础依赖见 `requirements-b.txt`。重跑 OCR 另装 `rapidocr-onnxruntime==1.4.4` 与 `onnxruntime>=1.18,<2`，仅使用本地 CPU 模型。

## 复现

仓库根目录，不安装 OCR 也能重放实际 OCR 快照及故障回归：

```sh
python -m unittest discover -s tests -v
python tools/replay_b.py --out data/runs/46007447-replay
```

完整原图重跑：先把来源包解压到 `data/runs/46007447-source/`，使该目录下存在 `source.json` 和 `assets/`，再运行：

```sh
python tools/offline_b.py --source data/runs/46007447-source/source.json --context tests/fixtures/book46007447/context.json --review tests/fixtures/book46007447/review.json --reference-export data/runs/46007447-source/paper-questions-original.jsonl --out data/runs/46007447-offline
```

`--reference-export` 可省略。它在图谱和检查完成之后仅用于诊断历史导出，绝不参与配答。
可加 `--evidence <先前baseline-evidence.json>` 复用全页 OCR；仍重新校验来源文件字节、尺寸、书籍、范围、摘要、OCR 框和临时格式，不能拿别本书的缓存继续。
输出目录必须不存在，防止覆盖旧交接。

## 第 4 题回归

第一章 / 1 探索勾股定理 / 第 1 课时 / 印刷题 4：原图答案为 `13`，原始历史导出为 `1:3`。三倍行重检本次取得 `4.13`，组装答案值为 `13`，原图框绑定 viewer-173。

预期 13 来自原答案图复核，并可由题干独立算出：AD=6 且 BD 为 AC 中线，所以 AC=12；AB=5 且 AB⊥AC，所以 BC=√(25+144)=13。该算式是固定案例的解释，当前没有通用数学求解器。
`1:3` 触发 `ANSWER_SCALAR_FORMAT`；`12` 触发 `ANSWER_VALUE_MISMATCH`；恢复 13 只消除该项错误，不使整批 PASS。任务状态 SUCCESS、导出成功或高置信度均不能绕过检查。不对其他比值答案全局删冒号。

另一个实际问题：第 7 题在全页 OCR 为 C，局部 OCR 却为 0。保留差异并报告 `OCR_RECOGNITION_DISAGREEMENT` 和 `CHOICE_ANSWER_FORMAT`，不把放大结果一律当真值。
