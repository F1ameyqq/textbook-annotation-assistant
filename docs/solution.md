# 推荐方案：三层分离 + 坐标标定前置

> 状态：方案定稿，实测数字待各路线调查完成后回填（见 §7）。
> 结论优先：**不要让视觉模型直接输出坐标。** 这是本方案与"VLM 直接出框"路线的核心分歧。

---

## 0. 一句话方案

**「坐标标定 → 本地检测出候选框 → 角色判定与配答 → 按平台格式执行」四段流水线，
每一段可独立验证、失败可回退，坐标问题在最前面一次性解决。**

---

## 1. 为什么不能让 VLM 直接出框

用户最初倾向「路线 B：VLM 直接出框」。本项目实测证据指向一个更稳的拆法：

1. **坐标不可靠。** 平台自己的历史数据里，同一条记录的 `rect_bbox` 与页图就不是同一坐标空间
   （页 234 见 README §2.3）。如果连"框到底画在哪张画布上"都需要专门标定，
   那么再引入一个"会幻觉坐标、格式不稳定"的 VLM 直接产坐标，等于把两个不确定性叠在一起。
2. **VLM 的强项不是像素，而是语义。** "这段文字是题干还是解析"、"这个选项属于哪一题"是语义判断；
   "文字块的边界在哪"是像素判断。让本地检测/OCR 给边界，让模型给标签，各自做擅长的事。
3. **可验证性。** 本地检测的候选框可以与人眼/历史框做 IoU 对比，误差可度量；
   VLM 直接吐的坐标一旦错，很难定位是"没看见"还是"坐标算错"。

因此路线 B 降级为**兜底与对照**，不作为主路。

## 2. 四段流水线

### 段的职责与接口

```
[1] 坐标标定  ──► 标定参数（画布尺寸 / 是否需要分栏偏移）
[2] 版面检测  ──► 候选区域 bbox（像素空间，无角色）
[3] 角色与配答 ──► 每个区域 → Q / W / A / E + 题目身份
[4] 执行与回执 ──► 裁剪图 + 平台所需字段（人工确认后提交）
```

### 段 1：坐标标定（必须最先做，且只需做一次）

**问题**：平台的 `rect_bbox` 以什么为画布？下载的 OSS 图与它差多少？

**手段**：一次**最小线上往返**——在测试书上建 1 个框 → 读回 → 反解映射。

可行做法（需用户授权，Phase 2 范围）：
1. 在已知页面已知位置画 1 个框，`rect_bbox = (100, 100, 300, 200)`；
2. 立刻 `get_manual_annotations_unified` 读回；
3. 若读回值不变 → 记录坐标即像素坐标，直接用；
4. 若读回值被缩放 → 从比值得到画布尺寸 `W_canvas = W_img / scale`；
5. 特别验证**拼合宽图**（页 233/234）：框画在第 k 个子页上时，读回的 x 是否含偏移。
   这一步直接解决 README §2.3 的谜团。

**在此之前**，所有离线产物一律输出**归一化坐标**（`x/W_img`、`y/H_img`），
这样标定结果一确定就能整体换算，不需要重跑检测。

> 如果用户暂时不授权写操作：退路是用**页面 DOM 尺寸**推断。查看器画布尺寸可从
> `client = origin + offset + scale × original` 这层映射反推（交接材料 §4 已记录该公式），
> 只需读取（导出/界面）不需要写。

**验收**：给出标定参数与不确定性；用页 8 那条 `x2=1181.09 > 1176` 的越界框验证
（它要求画布宽 ≥1181.09，可反推 scale 上界）。

### 段 2：版面检测（本地，零 API）

按成本递增顺序尝试：

1. **投影 + 连通域轻量基线**（零下载）：行投影切题块、列投影切选项、连通域合并成块。
   对**单一页扫描**（页 7–10）通常够用。
2. **RapidLayout / DocLayout-YOLO**：通用版面类别（text/title/figure…）。
   若引入，只用于"区域切分"，**不用来定 Q/W/A/E 角色**。
3. **拼合宽图**（页 233/234）：先按 `layout_probe.find_gutters` 的内部纵向沟
   切成子页，记录 `(offset_x, offset_y, scale)` 后**在子页内检测**，
   最后把坐标回投到宽图并去重。绝不把宽图当单页处理。

**为什么不用 YOLO 直接微调四类**：样本只有 14 题 / 36 框，类别极不均衡（analysis 仅 1 条），
直接微调必然过拟合。先用规则+弱标注把样本量做起来，再考虑微调。

### 段 3：角色判定与配答（语义层）

- **输入**：段 2 的候选区域 + 区域内 OCR 文本（局部 OCR 成本低）。
- **判定**：优先**可解释规则**：
  - 以"数字+顿号/句点"开头的行 → 题干起点；
  - `A. B. C. D.` 或 `（1）（2）` 模式 → 选项/小问（**每选项单独成框**）；
  - 「【答案】」「【解析】」等标记 → A / E；
  - 页脚/页眉模式 → 丢弃。
- **不足时**再上 VLM，且**只让模型输出标签与层级，不让它输出坐标**：
  把候选框编号后连同裁剪图一起给模型，要求它返回 `{"1": "question", ...}` 这类结构化结果，
  坐标仍来自段 2。这样模型出错时最坏情况是"标签错"，而不是"框飘到页外"。
- **配答**：以 `order_in_level` 为主键，**必须同时保存**
  书籍 + 目录路径 + 印刷题号 + 平台题序 + 来源页 + 子题号。
  原因：印刷题号**按课时重置**（交接材料 §2），凭印刷题号全书匹配必然错配。

### 段 4：执行与回执

- 产出裁剪图与平台字段（`rect_bbox / page_index / question_order /
  image_order_in_annotation_zone / order_in_page / parent_rect_id / directory_id`）。
- **只做增量的建框/改框**；平台保存是增量式（零改动不产生请求，已实测）。
- **不接** `commit_unified_submit` / `commit_unified_submit_and_async_ocr`。
- 每条写入都要有回执记录：请求参数、响应、读回校验值；读回不一致就停下并重新读取，
  不重发整题。

## 3. 中间结构（工程地基）

不要只存"最终 JSON"。每道题保留：

```
题目身份   book_id + directory_path + printed_no + platform_order + sub_no
来源       page_index, source_image, panel_offset(若拼合), bbox(原图像素)
片段       一题多物理片段，各自 bbox + 角色
内容      题干/选项/答案/解析文本（LaTeX 原样保留）
关系       父子(组合题)、跨页续接、选项归属
异常       越界/重叠/低置信/OCR 失败 标记
回执       平台返回 + 读回校验
调用记录   模型名、tokens、费用、耗时
```

保留"异常"和"调用记录"是成本口径的基础：**成本 = 全部调用费用 / 人工验收通过题数**（失败跳过计入分子）。

---

## 4. 成本控制设计

| 手段 | 效果 |
|---|---|
| 检测全本地 | 出框零 API 成本 |
| 局部 OCR（只裁候选区）而非整页 OCR | 大幅降 token/算力 |
| 批量单次调用 VLM 判角色 | 一张图一次调用，而非一框一次 |
| 归一化坐标 + 一次标定 | 不需要为标定反复调用 |
| 规则优先，VLM 兜底 | 常规题完全不花钱 |

---

## 5. 评测口径（不达标就是没做完）

**必须全测，不能只看 IoU 或 JSON 可解析率：**

1. 漏题率 / 重题率
2. 题干完整性、**选项级**完整性（每选项独立框，历史合框口径不可作真值）
3. 答案解析归属正确率
4. 目录与题号重置处理正确率
5. 图表与公式保真度
6. 跨页完整性（同题跨页不断裂）
7. **人工修正比例**（最终验收指标）

**调参用过的题不算验收成绩**，需要独立验证样本。

---

## 6. 风险与对策

| 风险 | 对策 |
|---|---|
| 坐标空间定义未定 | 段 1 标定前置；离线一律输出归一化坐标 |
| 拼合宽图切分错误 | 用贯穿式空白沟判据；人工复核子页数 |
| 组合题小问在导出中被合并成长字符串 | 以**框**为准重建结构，不依赖导出的字符串切分 |
| 样本过少（14 题 / analysis 仅 1 条） | 先规则+弱标注扩样，再考虑微调 |
| 8GB 显存 | 检测走本地轻量模型；VLM 用 4bit 量化或小参数模型 |
| 平台写接口未实测 | 任何写操作前先做最小往返验证；不碰提交接口 |
