# A30 客户无需 agent 独立验收

先读同目录 A30-customer-independent-production-20261024.md。以用户选书/范围或提供原始材料为起点，验收程序是否承担过去由agent完成的准备。检查普通用户是否仍须手写manifest、候选、哈希、题框ID或改代码；存在任何此类常规依赖就不能称客户独立生产完成。

与作者分离，只消费固定代码和原始输入。作者尚未固定前可制定有限标准、选择现有材料中的独立输入，不检查作者活动工作文件。新差量检查聚焦真实缺口；不重跑历史套件、九题保存、旧OCR或已耗平台轮次。

重点：一般输入到source/context/识别/组题配答/异常审校/生产计划是否连通；正常项自动推进，异常项可由普通用户处理；旧内容保全、防重复、未知保存先对账、失败接续；课时身份和题数不是硬编码；部署包有准备依赖和单一入口。不可仅凭合成通过、缓存候选或强制放行HOLD接受实际识别质量或客户生产。

阶段结论如仅离线实现或缓存消费，应准确标明，客户就绪仍待真实普通输入闭环。开发验收不成为客户每次运行的外部审批依赖。1800-a暂停，平台/凭据/付费模型实际调用0，等待另行确切执行绑定。固定报告要短且可核对，不加无关门槛；具体阻断交根协调，收到修复后只验相关增量。
