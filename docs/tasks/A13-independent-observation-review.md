# A13 独立只读验收

依据 [A13唯一观测](A13-single-reuse-observation.md) 新建正式独立验收对话。先准备标准并停止等待，不提前读取执行中输出或访问平台/profile。执行者固定raw报告、单次所有结果及精确释放后，调度另派固定隔离材料；只在本对话进行静态核证，不重放live或任何旧suite。

核固定53输入/产品/候选/独立R1通过身份；唯一共享启动目录/标记未重置，profile仅元数据绑定，实际占用检查在导航前、未证明则停；外层唯一启动及内层唯一导航、严格TLS和原allowlist/GET边界、0登录/业务/书籍接口。检查观察与guard最终状态、首错误、NOT_RUN及报告措辞，不能按URL或200认认证。

核外层Popen/内层worker及Job精确创建退出/句柄/资源释放。若失败/UNKNOWN只能接受失败归档和释放，不证明根因、认证或书籍可用；若LOGIN_REQUIRED，如实确认需要登录但不授权登录或再观测；若AUTHENTICATED_VIEWER_OBSERVED，最多确认这一次受保护界面观察。完整来源/目标、文字wire、题框保存读回仍未完成。

新输出目录及白名单在固定交付派发时给出；不改原记录或产品，不重新扫描实际profile占用，不补做失败后继。报告raw清单/摘要、限制和释放后停止。平台启动/登录/业务/旧suite次数均0，不借验收创建第二会话。
