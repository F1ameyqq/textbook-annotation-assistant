# A15 独立预检与唯一观测核证

先读[A15执行任务](A15-certificate-exception-reuse.md)、用户决定原件和固定提案；初始只准备标准，等待作者固定交付与释放，不读活动目录，不访问平台/profile/进程。

调度固定raw隔离目录和输出白名单后，核R1旧成员原bytes、差量仅在本轮批准门禁/新路径/证书例外所需范围，默认严格校验。独立从权威用户决定/任务推导字段与拒绝条件，不以作者自报为标准。核显式开关、激活摘要、任务/用户决定/提案/候选/调度ID/target/profile指纹/路径/额度/期限绑定在任何实际资源动作之前；一次性标记独占，旧A13路径不动。

按冻结有限E1–E4做唯一新纯离线差量，0子进程、browser、network、profile、真实占用；不复跑N1-N3/D1-D8/作者旧suite。首异常停、后继NOT_RUN，不修改候选或补跑。静态核保留逐跳/方法/WS与DOM后guard最终判定；本阶段0实际证书例外。核外层计时与精确句柄释放边界，尤其不能沿用A14未经证明的跨进程时基或“关句柄等于进程退出”。

预检交固定报告、独立原始结果、清单和释放，明确仅离线有限资格，不能自行激活live。主调度随后若派发唯一live，只由执行对话完成；该交付固定释放后，本验收对话再静态核本轮原始结果和实际scope/退出身份，0新平台访问。两次交付分别封存，不覆盖预检或旧失败。真实保存、书籍完整读取和登录提交均不在本任务接受范围。
