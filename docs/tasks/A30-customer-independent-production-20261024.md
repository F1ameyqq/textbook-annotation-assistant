# A30 客户无需 agent 的准备与生产入口

用户于 2026-10-24 明确：客户没有 agent，交付后不能每课时依赖开发者长时间准备。本任务接续原自动生产目标；A29 的本机有限运行包接受保持，但不等于客户独立生产验收。

## 执行目标

复用现有程序、B 识别/组题配答与审校组件、A27 稳定性和 A28 保存/读回能力，提供客户普通输入驱动的准备与执行流程。正常输入是选择书籍、课时/页范围或导入已有原始材料；不能要求客户写 Python、JSON、manifest、SHA、固定题框或接受标记。

客户操作终点应为：首次环境/登录配置后，选范围并启动；程序取得或导入来源、识别组题配答、生成题框及生产计划，正常题自动推进；低置信或缺材料项进入已有异常审校入口；保存后独立读回并导出。没有外部聊天 agent 才能运行。开发时独立代码审查不作为客户每次任务的运行依赖。
