## 2. 目标及独占改动范围

将已验证过的临时浏览器操作整理为可复用的只读适配：采集来源、当前目标快照、原图及查看器映射，管理专用无头会话和失败释放。

- 唯一代码范围：`src/annotation/source/usense/`、`src/annotation/delivery/usense_readonly/`、`src/annotation/runtime/browser/`。
- 专属辅助范围：`tests/test_a04_*.py`、`tests/fixtures/a04/`、`docs/evidence/A04/execution/`、`docs/tasks/A04-execution-report.md`；入口、复现和限制放证据目录 README。
- source 与 delivery 复用受控采集器，分别输出来源与平台业务视图；浏览器生命周期不包含题型、组题或配答规则。
- 不改 contracts、geometry、C01 样例、公共政策、根依赖、父目录公共入口、旧工具或其他任务范围；需要变更时给调度最小提案与失败输入。
- 本地登录工具作为现有依赖使用；确需新增依赖或公共入口时由调度整合，不在任务目录偷偷维护第二套公共实现。

## 3. 线上范围与会话使用

- 只读目标固定为 `46007447`《名校课堂八年级数学上册》；旧书 `46006966` 仅能作为明确标注的离线样例。
- 复用[已授权登录方式](../local-login.md)，由工具内部读取本机配置；不显示或复制凭据，不把其内容放进命令行、日志、样例或提交。
- 使用 `.local/` 下专用 profile、独立无头浏览器及固定 viewport；一 profile 一进程，不接管日常 Edge，不关闭他人浏览器。
- 启动前核对调度占用、实际进程/锁及目标；有占用冲突立即报告，不能删锁或杀进程抢占。记录本任务的占用与释放证据。
- 业务读取只允许已核对目标的 GET 与页面导航；现有登录流程的必要请求单独允许，不能据此允许任意非 GET 请求。
- 禁止画框、编辑、删除、OCR、保存、书级送审/送交及重放 A05 题 22。题级“提交修改”也属于本任务禁止的保存操作。
- 以动作白名单和网络拦截共同约束；未知业务变更请求阻断并报告。脱敏审计只留方法、受控路径类别、允许/阻断、结果与时间，不记录请求体、auth header、cookie、token 或原始敏感 URL。
- 证书忽略只可显式使用本次已明确授权的现有 `--ignore-https-errors` 参数；默认仍校验，不扩大到全局或更改日常浏览器设置。
- 不调用付费模型、不自动扩大页范围。真实采集限目标正文页 14、答案页 173 及一个用于翻页验证的相邻正文页；执行前核对当前页资源映射，缺页/错页时报告，不自行替换整书扫描。

## 4. 开发与证据要求

1. 离线先用已脱敏固定响应实现解析、引用校验、错误分类及会话状态测试；模拟结果显式标记，禁止以历史快照冒充实时采集。
2. 通过公共 API 生成 `SourceBundle` 与 `PlatformSnapshot`，记录实际目标、观察时间、版本/摘要、目录、题/框引用、范围和来源证据。
3. 元数据总页数与实际取得页数分开；保存原图字节摘要、真实尺寸、包内相对路径和外部页码映射。下载失败、来源不完整不得填成功或伪造完整性。
4. A05 的“22 题 / 68 框”是历史比较值；本次必须读取当前状态，不因数量变化直接覆盖数据，也不默认历史数量仍成立。
5. 真实检查登录、书籍 ID、原图加载及翻页；成功须有保护界面和内容证据，单独 URL 跳转或 HTTP 200 不足以证明完成。
6. 在 A01 geometry 版本发布后验证实际原图到当前查看器的坐标对应；记录 viewport、缩放/平移及原图身份，不将两页观察外推为固定全局偏移。
7. CSS/查看器适配仅在平台层；原图通用坐标消费公共 geometry。独立参考点及正反检查须能发现错误映射，不能只验证同一实现的自洽。
8. 能力字段按证据赋值；本任务未实测的写入、OCR、批量保存和恢复能力保持 `UNVERIFIED`。引用 A05 时附原证据与受限范围，不升级为通用能力。
9. 登录失效、目标错误、资源加载失败、超时和占用冲突均返回可定位错误；所有退出路径释放本任务资源，异常报告脱敏，不持续重试登录。
10. 执行完关闭自有浏览器，记录 profile 已释放，再交付独立复验；执行与验收不得同时占用同一 profile/书籍会话。
