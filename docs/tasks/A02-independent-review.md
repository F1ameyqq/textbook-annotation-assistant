## 独立检查

1. 在确切提交复现作者命令与 C01 受影响检查，记录环境、退出码、输出及未运行项；自报测试不能替代下面的独立反例。
2. 阅读三模块实现，确认 targetcheck 真正计算目标条件、planner 真正生成计划、mock 真正改变状态；无预制回执、跨层修改、私有合同导入或禁改路径变更。
3. 自行构造合法空目标、非空目标新题、明确已有题映射；再注入缺目录/题 ID、错平台序号、空字符串、动作与图谱错映射及 null 绕过，检查接受与拒绝均符合合同。
4. 独立变更图谱/政策/快照版本，去除或替换两阶段 PASS，注入授权错书/错范围、未决政策、能力 UNKNOWN/错平台版本；确认生成和执行两道门均关闭且目标未变。
5. 用两章节同题号、多片段和选定答案测试动作身份/来源闭包；手工计算预期框、依赖与前置事实，检查前一步正常变化不误触发外部冲突。
6. 分别注入生效、未生效、生效后响应丢失及读回矛盾；从模拟状态与日志独立核对回执，不能只比较执行函数返回值。
7. UNKNOWN 后换 action_id、run_id、另一题与 scope，确认同书保持阻断、未重复执行、历史未删除；另一书可独立模拟。NOT_APPLIED 也不得自动重播旧计划。
8. 检查分母包含异常、跳过及未入图谱项；只有框已保存时内容必须 PENDING，提交仍 NOT_SUBMITTED，不得进入 COMPLETED 或宣称内容质量通过。
9. 检查 UPDATE 基线及能力门；支持范围外明确阻断。确认未越界实现 A03 持久恢复、虚构 ReconciliationResult 或清除 UNKNOWN 解锁。
10. 检查产物经公共 API 验证、精确依赖与模拟标签完整；记录合同已保证与 A02 实际新增保证的边界。

报告给出被验提交、复现命令/结果、独立用例与证据路径、逐条结论、失败/未执行项、限制及 ACCEPTED / REWORK / BLOCKED；关键失败须有最小输入和实际输出。
验收者不自行集成或释放 A03；由主调度复现、记录集成提交与受影响检查后决定下一步。模拟验收不宣称真实平台、算法或 B 侧接口已被接受。
