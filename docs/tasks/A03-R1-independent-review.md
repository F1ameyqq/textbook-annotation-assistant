# A03-R1：等价内部替代独立验收

2026-10-18。与[A03-R1执行任务](A03-R1-equivalent-runtime.md)共同构成本轮固定范围。新验收对话只承担独立判断，不写产品、不管理B、不恢复旧库。

## 交付前

阅读主目录当前AGENTS、coordination、development-plan、执行任务和原28项映射。只确认范围和等待条件，回复 `WAITING_FIXED_DELIVERY`；不审浮动代码，不启动测试/产品/SQL，不自行轮询或唤醒作者，不另开一轮设计评审，也不必创建准备报告。调度交确切候选/证据与释放后才续派正式验收。

## 交付后

以调度给定的确切提交及必要依赖建立隔离审查副本，保持旧报告/证据原字节。核对允许路径、实际采用/pins、公共行为与原28项覆盖映射。重点判断替代路径是否确实接入正常执行、未决恢复和正式报告，是否仅改测试时限、只缓存PASS或跳过实际依赖检查。

复用既有正常/异常/UNKNOWN用例及已接受有限证据，针对新消费者做有界独立复现。M五例原每候选5起点/11dispatch上界沿用；L/G/F按原矩阵未闭合和实际改动选取，不能新增全交错/无限新矩阵。完整输入、真实独立进程/目标读回、动作效果与正式回执的区别、owner/进程释放仍需核对。

检查核心等价：持久intent先于效果；重启先reconcile；UNKNOWN整书暂停且跨scope完整扫描；动作去重/旧代次与证明失效；充分/不足ABSENT与未尝试项；hold最终读/CAS后重新INITIAL和规划；历史、完整分母、PENDING/NOT_SUBMITTED。资源/pins/root/registry/每consumer声明变化不能被复用结果绕过。优化纯计算不能代替实时资格。

45秒不是业务验收条件。消费作者冻结并说明的外层防挂死预算，原内部期限不放宽；分别报告功能结果、实际耗时、结构变化和未测性能。若同一候选超时，不静默延长重跑；给最小具体失败/未证明范围。实现失败交作者一次有界返修建议，不自修产品或反复增加标准。

输出 `docs/tasks/A03-R1-review-report.md` 和必要最小证据 `docs/evidence/A03/R1/review/`，提供确切审查版本、复现命令、原28项结论和自有资源释放。可以判有限ACCEPTED/REWORK/BLOCKED，明确适用范围；A03整体及I01释放、主目录集成仍由调度决定。真实平台/B共同合同不在本次通过范围。
