## A01：静态来源与公共几何

唯一写入范围：`src/annotation/source/static/`、`src/annotation/geometry/`，以及 A01 专属测试、样例、说明和报告。**公共 geometry 由 A01 独占实现**；不承担识别、组题或平台 CSS 适配。

输入为现存、可核验的离线资料：`技术证据/只读样本-46006966/` 的原图、导出和清单，以及 `docs/evidence/A05/` 的新书脱敏来源证据。两本书分别生成来源包，不能混用书籍 ID、页映射或验收结论。原始文件只读，输出写新目录。

验收边界：

1. 通过公共 API 生成并消费 SourceBundle，记录原图字节摘要、实际尺寸、来源、目录与外部页码映射。元数据页数和实际取得页数分开，缺少原图和映射不明必须报告。
2. 把完整输出复制到另一个含空格的目录后仍能消费；无个人绝对路径、失效资源引用或写回原件。导入前后原始资料摘要一致。
3. 历史导出保留原件和质量标记；不把原有框、OCR、题序或人工整理清单当成独立金标准。`scope_manifest` 的来源和完整性依据须明确，不能用现有识别结果冒充全页无遗漏的分母。
4. geometry 给出原图、处理图间可复现的正反变换。先明确缩放、偏移、旋转中心/方向、补边和操作顺序；若现有合同未说明，列为语义提案，不静默猜测。测试使用独立计算的已知坐标，覆盖缩放、裁片、旋转和组合变换。
5. 拒绝错误尺寸/摘要、非有限坐标、不可逆变换和越界框；不通过自动裁边掩盖错误。声明支持的变换范围及误差容限，范围外显式失败。

结果只证明静态来源可追溯和受支持的几何运算成立，不证明全书采集、切题、配答或历史答案正确。

## A02：计划、目标检查与模拟执行

唯一写入范围：`src/annotation/delivery/planner/`、`src/annotation/delivery/mock/`、`src/annotation/quality/targetcheck/`，以及 A02 专属测试、样例、说明和报告。不改 source、geometry、B 的 precheck/coverage 或运行时持久化。

输入为 C01 已接受版本的固定图谱、检查报告、政策和模拟快照。消费公共 API，实际计算计划和回执，不能只返回固定样例。前置内容质量用明确标注的合同桩；targetcheck 自己计算其负责的目标状态结论。

验收边界：

1. 两份不同阶段的 PASS、相同图谱/政策、当前目标快照和授权范围一致时才能生成可执行计划；未决政策、能力未验证、快照变化或缺任一检查必须阻断。
2. quality 只生成报告；planner 只生成动作与预期效果；mock 才改变模拟目标。算法和通用合同不依赖浏览器，所有回执显式 SIMULATED。
3. 动作身份独立于印刷题号和平台顺序；两个章节同题号不互相覆盖，修改目标版本不能继续消费旧计划。保留全部范围项、异常和跳过分母。
4. 至少覆盖明确生效、明确未生效、已生效但响应丢失三种故障。超时无充分证据时输出 UNKNOWN，暂停同书后续计划；换动作 ID、换运行 ID 或换另一题不能解除暂停。
5. 明确未生效也需重新检查目标，不自动重发旧动作。模拟器需给出可独立检查的动作日志和目标状态，不把自己的返回值当读回证据。
6. 框保存、内容校验、最终提交分别记录。内容未核对保持 PENDING；本阶段不生成真实平台通过结论，不扩展成 A03 的跨进程恢复实现。

UNKNOWN 的持久化和解除暂停依赖 A03。当前缺少正式 `ReconciliationResult` 实现；A02 记录接口缺口，不通过删历史或私造字段绕过合同。

验收边界：

1. 独立无头浏览器可检查登录、实际目标、原图加载、翻页和目录只读信息；不占用或控制日常浏览器。开始和结束均有会话/profile 占用与释放证据。

4. 业务数据读取限定 GET 与页面导航；登录请求单独允许。禁用画框、保存、删除、OCR 和书级提交的动作及端点，并保存脱敏网络审计，证明实际未触发这些调用。不要记录 auth header、cookie、token 或含敏感参数的原始 URL。
5. 登录失效、目标不符、原图失败、超时、占用冲突均明确报错并释放本任务资源；不得关闭他人浏览器。离线故障注入和真实会话测试分别标记。
6. 本阶段没有真实写入探测；无法通过本次只读证据证明的写入能力保留 UNVERIFIED。已有 A05 有界结果引用原证据和适用版本，不扩大为通用 OCR、批量保存或恢复能力。
