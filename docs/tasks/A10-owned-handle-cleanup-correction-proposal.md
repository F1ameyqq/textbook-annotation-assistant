## 已确认的具体缺口

固定 `docs/evidence/A10/local-correction/bounded_checker.py` 第97–104行把 stdout、stderr 与自有 Popen 句柄关闭放在同一个 try 内。若 stdout.close() 或 stderr.close() 抛异常，控制流会直接进入 except，跳过其后的关闭调用。该路径返回失败，不能产生0占用的成功结论，但未保证逐个尝试释放自有资源。

## 建议的唯一差量

若获准新增此有界纠正，只调整上述清理段及对应离线测试/新证据：

- stdout 与 stderr 各自独立 try/except；一个关闭失败不妨碍另一个关闭尝试。
- Popen 原始句柄关闭置于独立 finally 路径，始终尝试；只有该 Close 实际成功才记 handle_closed=true。
- 任一流/句柄关闭失败仍使总体失败；进程退出身份未证明仍保留，不得被句柄成功关闭覆盖成成功。
