## 来源输出与验收条件

1. 使用 C01 接受版本的公共类型及 load/validate/seal API，分别生成书级隔离的交换包；不手写另一套合同或靠内部私有字段绕过校验。
2. 图像实际解码可读，记录摘要、尺寸、asset_id、来源和外部页映射；拒绝损坏图、错误声明尺寸/摘要、缺少必需资产及映射矛盾。
3. 显式选择处理范围，区分 expected、acquired、元数据总页数及缺页；历史快照保留观察时间，不生成伪实时 PlatformSnapshot。
4. 历史标注/导出原件字节保留并标为未经独立业务核准的参考；越界框保留于历史资源，不静默裁边或包装成合法通用框。
5. 原来源清单中的本机/外机绝对路径只作为输入解析线索；原件留原仓库，输出建立脱敏、包内相对的来源引用和原清单摘要，不要求消费端访问旧路径。
6. `scope_manifest` 必须说明题目清单如何选取及完整性限制；历史14题、A05单题或候选列表均不能冒充整页/全书独立分母，不伪造覆盖 PASS。
7. 合同若不能表达范围未知或缺失来源，交付明确的限制/失败报告和最小增量提案；不得编造题、设假完整性或修改合同解锁。
8. 完整输出复制到另一个含空格的目录，从不同 cwd 用公共入口消费仍通过资源校验；禁止依赖仓库外文件、绝对路径、逃逸链接或隐式网络。
9. 重复导入不得覆盖原资源或旧产物；身份生成规则可解释且独立于印刷题号，输出新修订时说明依赖版本及摘要。

## geometry 语义、支持范围及验收

通用坐标为原图连续像素坐标，左上原点、x向右/y向下，bbox `[x1,y1,x2,y2]` 为半开边界；绑定 asset_id、尺寸及摘要。
实现前在专属说明固定变换规范版本：裁片偏移的坐标域、正向/逆向、缩放单位、旋转原点/中心和正方向、补边位置、操作先后及输出尺寸。
明确区分像素边界与像素中心；变换点及框四角，不能仅变换左上/右下后假定所有旋转仍成立。
首版至少支持恒等、裁片平移、正比例独立x/y缩放、四边补边、90°整数倍旋转及其组合，写明有限数值、可逆条件和误差容限。
任意角度、透视/非线性、反射等若未支持须显式拒绝；若支持任意角度，明确轴对齐包围框的信息损失，不能声称框回投精确可逆。
C01 对旋转中心/操作顺序未明确的部分作为 A 内部具名提案，不能默认为共享约定；禁止从模糊 crop_transform 静默推断矩阵。需要跨侧语义扩展时只提交提案。
正反测试同时覆盖点与框，包含非方图、非零裁片、不同x/y比例、非对称补边、90/180/270°和组合；预期值由手算或独立公式得出。
必须有能区分旋转原点、旋转方向和“先缩放后偏移/先偏移后缩放”的反例，不能只测正逆相消或调用自身函数生成预期值。
拒绝 NaN/Inf、零尺度、不可逆矩阵、负面积、错资产绑定及越界框；不通过自动裁边、自动改尺寸或容差吞掉实质错误。
浏览器 CSS/DPR 映射不在本任务内；A04 将消费这里被接受的明确 API 和版本，不复制一套通用几何。
