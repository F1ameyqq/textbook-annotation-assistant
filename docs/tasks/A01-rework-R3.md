## 本轮仅两项

### R3-01：URL 身份必须来自实际 path

当前 `importer.url_index()` 用 `urlsplit` 检查 scheme/host，却对整个字符串做尾部正则；query/fragment 中的路径文本可替代实际资源路径身份。必须从真正 path 核对两处书籍标识和 source index，query/fragment 不得提供或覆盖身份。可忽略这些组件，或明确拒绝超出当前支持格式的组件；两者均须写清行为，保留既有合法直接 JPEG 地址与两书兼容。

复现原件只读：`docs/evidence/A01/review-R2/primary-url-path/Q01-cross-book-path-query-tail/`、`Q02-wrong-index-path-fragment-tail/`，以及来源子检查 U23/U24/U25。实际 path 错书但 query 含正确书、实际 path 错页但 fragment 含正确页必须在公共资源校验通过后被来源语义定位拒绝。

新增邻近用例覆盖 query/fragment 对调、错误路径两处书籍标识分别改变、错误源索引、合法直接路径和已声明组件策略。缺失实际匹配路径不能靠 query/fragment 构造身份。只解析归档字符串，不联网、不增加主机认证、签名URL或一般URL支持需求。
