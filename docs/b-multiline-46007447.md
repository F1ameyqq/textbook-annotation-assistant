# B 侧复杂答案与解析多行组装

2026-10-16，Asia/Shanghai；基线 `3224b8d3c620d63b0603a459ff75e26909d27fd3`，沿 PR #2 交接。本轮仅使用已留存的真实 OCR 快照与原图做离线开发，没有访问或修改网站，也没有重新调用 OCR 或付费模型。

## 本轮解决的问题

旧入口对长答案主要保留首行。现在按章节/课时窗口、主编号、标题和版面边界收集续行，保留分数碎片、分步解答和多个解法；在明确的下一题、标题或难度层级处停止。小数 `4.1=16.81`、小题 `(1)/(2)` 和分数数字不按主编号拆题。

“2 一定是直角三角形吗”第 15 题可由左栏底部续接到右栏顶部。每段保留独立原图坐标，不能用跨越两栏的大框代替。跨页续接尚无可靠来源合同，连号或相邻页也不能自动证明续题；对应候选保持 OPEN，等待明确证据。

显式 `答案/解析/分析/详解` 标签分别收集答案和解析，支持同行、独立标题和多行正文；`解/解法一/解法二/答` 本身不制造解析。没有解析正文时 `explanation_present=false`；只有解析标题没有正文时保留标题证据并报告 `EXPLANATION_BODY_MISSING`。同行分角色只有文本区间证据、没有逐字几何时保持 OPEN，不能据一个共享行框生成两个已核准区域。

实际样本没有独立解析 E 正文；解析分离能力由明确标记的构造案例验证，不声称在这本书上取得解析识别准确率。

## 输入、输出与版本

输入沿用 `b-evidence-trial/0.2`。本轮重放同一 OCR 快照，原图按原始 `source.json` 验证字节、SHA-256、尺寸、书籍、范围与资产描述。上下文章节窗口仍是原图目视开发输入，不是自动目录识别。

图谱升级为 `b-graph-trial/0.2`，检查报告升级为 `b-check-trial/0.2`，不覆盖或宣称冻结 A/B 公共合同：

- answer 新增 `fragments/regions/source_line_ids`、`assembly_status/boundary/assembly_flags`、`transcription_verified` 和解析字段。每个片段绑定原始 OCR 元素、原始文字与确切 `text_span`，结构性标题单独保留。
- `text` 仅组装答案正文；`explanation_text` 仅组装解析正文。结构性标签不混入正文，也不会失去来源。
- `answer_coverage` 对答案页每条原始 OCR 行保存一条账本，状态为 CONSUMED / UNASSIGNED / EXCLUDED，明确其题目、片段和字符区间分配。CONSUMED 表示有明确片段归属，不证明原图完整转写。
- `regions` 是逐片段几何投影；旧顶层 `bbox` 仅覆盖锚点所在栏，跨栏消费者必须使用逐片段区域。
- `assembly_status=BOUNDED`、兼容字段 `complete=true` 只表示**已有 OCR 的组装边界明确**，不表示文字、公式、图片或业务验收通过；`transcription_verified` 始终 false。不能将它映射为可提交状态。
- 新图谱/检查器必须按 0.2 版本消费；0.1 旧输出与验证记录继续保留。本轮未实现人工 patch 跨版本迁移。

## 独立质量检查

检查器不从组装结果生成预期。`review.json` 新增 9 个独立清点案例，绑定原图摘要、原始 OCR 文字摘要和确切字符区间。覆盖第 1 课时 6/15/16、第 2 课时 1/5/8、下一节 7/8/15。

逐项核对片段与原始 OCR、区域投影、答案/解析正文、覆盖账本和独立预期。可以发现丢失续行、重复消费、区域字段篡改、缩短公式片段、同时篡改片段及账本、章节串接和缺失来源。密集行的父行与细分 token 不重复计为独立已覆盖内容；不能可靠分割的行保留歧义。

原图已经确认而缓存 OCR 缺失的公式、变式行和题号作为独立问题保留。尤其第 2 课时原始行 79 混有多题，未分配给第 1 题；右栏第 16 题锚点缺失，8 条碎片没有接到第 15 题，也未补造题号。

## 复现与实测

仓库根目录；每个输出目录必须不存在：

```sh
python -m unittest discover -s tests -v
python tools/replay_b.py --out data/runs/46007447-multiline
```

若来源包已解压到 `data/runs/46007447-source/`，还可校验全部原图并生成题目/答案/解析叠框，不重新运行 OCR：

```sh
python tools/replay_b.py --source data/runs/46007447-source/source.json --out data/runs/46007447-multiline-images
```

结果：59 项回归通过（原 29 + 新 30）；34 个题目候选、56 个答案候选、27 个唯一同范围配答候选。14 个答案覆盖多个原始 OCR 行；141 个答案/结构片段。答案页 159 行中 100 行有归属、21 行明确标题等排除、38 行未归属。52 个候选组装边界明确，3 个 OPEN、1 个 AMBIGUOUS；这些数量不是准确率。

整批仍为 HOLD。38 条未归属记录、4 处已知原图/OCR 缺口、识别分歧、图像/公式范围等均保留。134 条报告问题包含不同检查维度，不能与旧版本问题总数直接比较。数值和产物摘要见 `evaluation/book-46007447-multiline.json`。
