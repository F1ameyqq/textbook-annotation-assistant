# 试题标注辅助自动化

面向教辅标注平台的辅助自动化项目：自动框选题干、选项、答案与解析，完成题答对应，由人工最终检查和提交。

## 当前进度

截至 2026-10-15，已完成需求整理、浏览器接入、只读页面体验和首批样本采集，尚未交付自动标注主程序，也未进行付费模型测试。

- 已取得当前样书的 4 张完整原图。
- 已关联 14 道既有题目、36 个历史框与目录归属。
- 已验证页码定位、缩放和平移等浏览动作。
- 新建框、跨页执行、保存及实际模型成本仍待测试。

## 目录

| 目录或文件 | 用途 |
| --- | --- |
| `原始资料/` | 客户原始需求和人工操作演示视频 |
| `技术证据/` | 页面核查记录、截图、原图、样本及当前站点构建快照 |
| `技术证据/只读样本-46006966/` | 首批原图、目录、历史框、内容导出及关联检查 |
| `只读核查工具/` | 早期只读检查脚本，不是自动录入主程序 |
| `文件清单与校验.json` | 早期归档文件的大小和 SHA-256 |

`技术证据/cached-js/` 是第三方站点前端构建的调查快照，用于复核当时的页面机制，不是本项目原创实现。归档资料通过 Git 属性保留原始字节，便于复核已有哈希。

## 样本和操作边界

当前样本来自既有平台结果，尚未独立核准为验收标准。已有框存在质量问题，不应直接作为准确真值；当前样本也没有同题跨页实例。

本次线上调查保持只读：没有新建、删除或修改标注内容，没有保存、提交或创建新的 OCR 任务。未来写入测试需明确测试题和允许范围，最终提交由人工负责。

浏览器临时日志、运行缓存和本机凭证文件已列入 `.gitignore`。仓库不包含浏览器登录配置或 API 密钥。正文中部分本地资料链接使用归档机器的 `D:\1800` 路径，其他电脑复核时应按自己的仓库根目录替换。
