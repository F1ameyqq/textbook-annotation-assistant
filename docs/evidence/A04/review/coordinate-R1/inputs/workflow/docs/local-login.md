# 本地登录配置

用户已授权：在本机文件填写 Usense 账号密码，由程序读取并用于该平台登录。

打开项目内 `.local/usense-login.json`，填写两个字符串并保存：

```json
{
  "username": "在本地填写账号",
  "password": "在本地填写密码"
}
```

双引号和反斜杠需要遵守 JSON 转义规则。文件兼容 UTF-8 BOM；密码中的空格和符号按原样保留。

- 文件为本机明文配置，整个 `.local/` 已加入 Git 忽略。
- 账号密码直接由脚本读取，不放进命令行参数、聊天或执行日志。
- 专用会话按账号隔离，保存于 `.local/browser-profiles/`，不使用日常 Edge 配置。
- 默认无头运行；该工具只登录及读取标注页，不选择书籍或修改标注。
- 验证码、额外认证或无法确认结果时停止，不连续尝试密码。

检查填写情况（不会显示内容）：

```powershell
python tools/usense_login.py --check
```

执行一次自动登录：

```powershell
python tools/usense_login.py
```

需要可见窗口调试时加 `--headed`。同一专用 profile 不要同时启动多个进程。运行结束会关闭专用浏览器并保留登录状态；这不会把登录状态复制到日常浏览器。

依赖本机 Python、Playwright 和 Microsoft Edge。成功判定要求读到受保护的标注界面，不能只看 URL 跳转或 HTTP 200。已完成一次真实账号登录和一次重开后的会话复用检查，结果见下文。

2026-10-16 首次实测：本地配置检查通过；专用无头 Edge 在打开 `https://www.usense.com/qieti/annotateUnified` 时返回 `net::ERR_CERT_COMMON_NAME_INVALID`，发生在账号密码填写和提交之前。只读复查登录页也出现同一错误。本机存在系统代理，因此尚不能把问题确定归因于网站本身。

工具默认保留 HTTPS 证书校验，不自动改域名或忽略证书错误。连接恢复后可重新运行上述登录命令；不会连续尝试密码。错误提示区分页面连接、填写、提交和页面确认阶段，不输出原始浏览器异常内容。

用户明确授权临时忽略证书错误时，可使用：

```powershell
python tools/usense_login.py --ignore-https-errors
```

该参数仅作用于本次运行的专用浏览器 context，不修改系统或日常 Edge 的设置，之后不带参数仍校验证书。目标仍限定为 `https://www.usense.com` 的已确认登录路径；页面必须出现既有登录表单才会填写凭据。跳过校验意味着本次连接无法通过证书确认服务器身份。

2026-10-16 用户明确授权后，携带该参数完成一次登录，读取到标注页。随后关闭并重新启动同一专用 profile，只读检查通过：仍在目标标注路由、应用标题匹配、已知 viewer 容器可见、登录密码框不可见；复用检查没有填写或提交凭据。三次重开检查中前两次页面加载未就绪并超时，第三次通过，尚不能据此保证加载稳定性。此结果只确认登录及会话复用，不代表书籍图片、目录修改或标注录入已验收。
