**假设规范**：原图连续像素边界坐标，先裁片→独立x/y缩放→补边→顺时针旋转，并将旋转后画布重定位至非负边界。此假设只用于准备。冻结交付后必须与作者具名规范逐项核对或调整；C01 未固定的语义不能默认为共享合同。

裁片为 `[cL,cT,cR,cB]`，补边顺序 `[左,上,右,下]`：

```text
u = sx*(x-cL)+左
v = sy*(y-cT)+上
A = sx*(cR-cL)+左+右
B = sy*(cB-cT)+上+下
90°:  (B-v,u)       输出尺寸 B×A
180°: (A-u,B-v)     输出尺寸 A×B
270°: (v,A-u)       输出尺寸 B×A
```

框独立变换四角再取最小/最大边界。逆向以本公式解方程为预期，不调用实现自己的逆变换生成期望。
