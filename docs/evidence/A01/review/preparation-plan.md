# A01 独立验收准备

日期：2026-10-16（Asia/Shanghai）。阶段：PREPARATION / WAITING_EXECUTION。
本清单不是实现测试结果。正式检查只消费主调度指定的冻结提交；不从活动执行工作树导入模块。

## 进入正式验收所需材料

1. 确切交付提交、冻结声明、base_commit/workflow_commit 与变更文件清单。
2. 执行报告、最短复现命令、依赖/环境、公共 API 及两书完整输出目录。
3. 来源导入前后摘要、资产清单、页映射依据、范围选择依据、缺失来源和历史质量标记。
4. 具名 geometry 规范版本、操作顺序、坐标域/旋转中心/方向、输出尺寸、容差及支持/拒绝范围。
5. 合法/非法输入、独立手算表、消费者与已知限制；合同缺口须具名提案。

收到材料后，在 `.local/stages/A01-review/` 创建由确切提交导出的隔离副本。记录 `git diff <base> <delivery> --name-status`，核对 C01 祖先和共享文件未改。每次运行先记录 `annotation.contracts`、source、geometry 的实际导入文件，防止现有 editable 安装指向其他工作树。只临时设置本进程导入路径，不重装包或修改全局配置。重跑作者实际交付命令；本轮未猜造尚不存在的 CLI。

## 几何检查矩阵（全部待执行）

必须按作者具名规范建立独立预期。没有规范则记录缺失，不替作者决定旋转中心或解释 C01 模糊字段。

- 分别测试点与框：非方画布、恒等、非零裁片、独立正比例x/y缩放、四边非对称补边、90/180/270°及组合。
- 显式检查输出宽高、四角取轴对齐包围框、正向精确值及独立逆向值；不以正逆相消作为唯一依据。
- 区分连续像素边界/像素中心、顺/逆时针、原点/当前画布中心、原图中心、先平移/先缩放。
- 几何负例：NaN、±Inf、零/负尺度、不可逆矩阵、错宽高/asset_id/摘要、负面积/零面积/越界框、任意角/透视/反射等未支持变换。
- 在最大边界和容差外各取一点，确认无静默裁边、自动改尺寸或大容差吞错；记录每项实际/预期及错误类型。

手算场景存于同目录 `geometry-hand-cases.md`，其假设规范仅用于准备；冻结交付后逐项匹配作者规范，不将其宣称为共享合同。

## 证据方式与限制

每条正式运行保留命令、cwd、提交/导入路径、退出码、完整日志、输入与期望、实际错误及 SHA-256。先重跑必要检查，失败保留最小输入；不替作者修代码。本轮仅准备材料和字节基线，来源解码、映射复核、跨目录消费、反例及 geometry 验收均未运行。

验收仅覆盖静态来源和声明的几何能力；不证明识别、配答、真实保存、全书覆盖、B确认、主调度集成或 A04 依赖释放。
