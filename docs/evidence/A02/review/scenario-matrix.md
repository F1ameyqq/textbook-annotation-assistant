## 构造与取证方法

正式复验只读取确切交付提交；必要时将该提交导出到 `.local/stages/A02-review/`，所有输入和结果仅写验收专属目录。记录 Python、依赖及实际模块导入位置，防止已安装包或浮动 worktree 替代冻结源码。先复现作者命令及受影响 C01 检查，再运行独立矩阵。

业务反例尽量保持合同结构合法：修改图谱、政策或快照后，通过公共 `seal_artifact` / `seal_policy` 重新封签并重建精确依赖，避免仅因旧摘要失败便声称业务门已经验证。引用/摘要错误另记合同层拒绝。分别记录拒绝发生在 C01、A02 targetcheck、planner 或执行入口；C01 已保证的约束不能计为 A02 新增保证。

每个案例记录最小输入、实际命令、退出码、错误定位、生成计划、回执以及可独立读取的模拟状态和追加日志。正常框数、原图绑定、来源闭包及依赖由验收者手算，不能直接拿作者 `expected.json` 或执行函数返回值充当真值。所有业务输入/效果证据标为 SYNTHETIC，计划/执行回执为 SIMULATED；只有诊断阻断链可用 NOT_EXECUTED。

拒绝路径比较调用前后状态、框数及日志，区分追加诊断记录与实际写动作；不要求拒绝时完全没有诊断日志。授权、政策、能力、快照的关键变化应分别覆盖计划生成和执行入口。

## 双 PASS、版本、授权与能力

| ID | 独立场景 | 预期及必须观察的证据 |
|---|---|---|
| G01 | 合法非空处理范围、平台目标为空、两处平台题 ID 均 null | TARGET 真计算为 PASS，生成 READY；空平台目标不等于零题范围 |
| G02 | 非空目标中有同印刷题号的其他题，新内部题两处 ID 均 null | 合法新建，不猜已有归属；生成及执行均通过规定检查 |
| G03 | 明确已有题映射，快照目录、题 ID、已有题序一致 | 合法生成；动作保留准确已有题 ID；模拟读回关联正确 |
| G04 | 移除 PRE_APPLY PASS | 拒绝 READY/执行；无实际写动作 |
| G05 | 移除 TARGET PASS | 拒绝 READY/执行；不凭 PRE_APPLY 单独放行 |
| G06 | 同一份报告重复使用，或两报告均为同一 stage | 不能充当两阶段 PASS；拒绝理由定位 stage/依赖 |
| G07 | 分别将任一阶段改为 HOLD、EXCEPTION、RETRY | 每个变体关闭相应资格门；若产生 BLOCKED 诊断计划则 actions 为空 |
| G08 | 图谱修订/摘要改变，同时包内保留合法旧修订和旧 PASS | 新图谱不能使用旧 PASS；不暗取最大 revision；明确绑定版本 |
| G09 | 政策修订或内容改变并重新封签 | 旧报告/计划不继续适用；政策引用与检查重新评估 |
| G10 | 计划后当前快照 revision/hash 改变 | 显式传入新当前快照，执行拒绝旧计划；状态无额外写入 |
| G11 | 授权书籍改为另一书 | TARGET、生成及执行均不得放行；检查前后目标不变 |
| G12 | 授权目录/页/题范围缩小，使某动作越界 | 可定位错范围；生成及执行门关闭；不得部分越界写入 |
| G13 | 必需能力为 UNKNOWN，其他输入合法 | 具体能力 issue；无 READY 或实际写动作 |
| G14 | 必需能力为 UNSUPPORTED | 明确阻断；不自动切换工作模式或降级操作 |
| G15 | 能力 VERIFIED，但证据适用 platform_version 与快照不同 | 不能凭 VERIFIED 字样放行；计划及执行均拒绝 |
| G16 | 分别测试 PERSISTENT、已显式选择的同会话模式所需能力 | 按实际模式检查 persistent_draft / same_session_handoff 及 frame_readback；不额外要求无关重启能力 |
| G17 | W 规则 UNRESOLVED、组合/七选五等未支持投影 | 受影响题明确阻断/异常；不把未决规则写成已确认政策 |
| G18 | 普通选择题 SYNTHETIC_ASSUMPTION，尝试提升为真实平台模式 | 只允许规定模拟路径；不能获得真实平台执行资格 |
| G19 | 输入报告称 PASS，但当前目标/授权/能力事实不满足 | targetcheck 独立计算具体失败检查及 issue，不能抄输入结论；目标未变 |
| G20 | READY 后独立改变授权、政策适用条件或能力版本 | 执行入口再次校验实际当前条件；记录拒绝层及无写入证据 |

| E08 | 任一故障发生于多动作计划中间 | UNKNOWN 后不继续同书后续写动作；已执行状态与完整历史保留；回执覆盖符合公共合同 |
| E09 | 检查独立读取接口与追加动作日志 | 日志不被重写，状态与返回值可以分开核对；重复调用计数可观察 |

## 验收覆盖与结论规则

独立验收任务第 1–10 条分别由 F01/F05、F02–F04/S08、G01–G03/I01–I09、G04–G20、S01–S07、E01–E09、U01–U07、B01–B05、U08–U11、F04/F05/B05 覆盖。冻结后按实际接口细分参数化用例，但不得省略上述业务观察层。

正式报告才给出 ACCEPTED / REWORK / BLOCKED，并绑定被验确切提交、实际命令和证据。未运行项不能标 PASS；关键失败必须保留最小输入和实际输出。主调度负责集成与 A03 依赖释放，本矩阵不改变调度状态。
