# B 侧长期目标与验收路线

设立：2026-10-17，Asia/Shanghai；本次扩展基线 `c89e38c`。最新实现、实际运行和交接版本见 [B 状态](status/b.md)，定稿边界见 [需求对照](requirements-confirmed.md)。B 负责离线识别、内容组装、配答及质量检查；A 负责公共合同最终合并、平台执行和平台保存/恢复。各自管理内部任务，接收验证由接收方记录。

## 长期终点

交付一条可处理整本教辅、可恢复且可接入 A 的内容流水线：由完整来源和目录生成题干、独立选项、答案、可选解析、共享材料、公式、图形/表格及跨页关系；每个内容片段可追到原图，遗漏、重叠、串题和歧义有明确处置。正常题在经独立验收的支持范围内自动推进到可复核结果，异常可定位、补读、人工修订并只重检受影响内容，最终由人工确认提交。

终点包括整书离线验收、跨书/版式的独立留出评估、A/B 固定消费者联调、获授权后的平台读回，以及可维护交付。局部样本、候选数量、测试数量、JSON 合法、阶段 READY 或结构审计 accepted 均不能代替这些证据。当前全部 HOLD 是开发现状；后续须建立有明确门槛的内容核准流程，不能通过删掉风险或修改状态字段获得放行。

## 分阶段交付与门槛

L1–L5 可并行推进：整书来源准备、独立样本设计和合同适配应与算法改进同步，不等待所有复杂公式解决后才开始。

### L1：完整内容与可靠配答

**可执行交付**：把多行正文、公式/二维结构、图形/表格、显式解析、共享材料和跨栏跨页关系纳入同一来源账本。保留全部原始模型结果与失败，补读只追加有来源的候选；有版本的选择或人工修订须说明依据并触发受影响范围重检。配答限定书籍、章节/课时、材料命名空间和印刷题号，缺少解析时不虚构解析；重复题号或未编号例题不得靠顺序猜关联。

**验收证据**：对冻结的真实正负例逐题核对题干、每个选项、答案/解析全文和区域；公式检查符号、数位、上下标、分子分母、括号作用域及顺序，不能只看语法可解析。覆盖 Q4 已知错误、Q16 二维顺序、Q9 跨页图形/正文、混合行分区及 19 条材料身份；检查漏片段、重复、串题、错误配答和错误放行。结构闭合与转写核准分别出具报告，未解决项保留 HOLD。

**外部依赖**：对应题页、稳定目录/材料 ID，以及独立人工核对的内容样本。B 可继续现有原图上的补读和故障回归，不等 A 提供平台 runtime。

### L2：整书可恢复内容流水线

**可执行交付**：在现有逐资产识别、细化、回补、组题配答、续接与当前质检上，接入有独立来源/版本的公式和正文补读、选择/修订及再质检。统一 CLI 接收完整声明范围，持久保存 intent、attempt、不可变产物和依赖；限量运行只限制本次工作量，不缩小整书范围。缺页、缺目录、待续接、未归属和不支持内容都列入待办，不能以异常页跳过换取整书完成。

**验收证据**：整书页清单逐项对账、独立题目/材料清点和配答关系对账；同一冻结整书从空目录完成一次，模拟进程执行中退出、物件已发布但事务未提交、局部损坏、输入/模型/规则/审核变更，再恢复并核对内容及引用。证明只重做受影响阶段，旧坏字节和失败 attempt 保留；审核单独变更不重跑无关 OCR；部分完成时不得输出假冒当前图谱的旧检查。记录实际模型调用、缓存命中、耗时和人工处理量。

**外部依赖**：可移植整书原图、预期页范围和目录、来源映射观察。必须区分完整原图、局部 OCR、视觉参考与已核准内容；完整来源未到齐时可交付可恢复局部运行，但不得宣称整书验收。

### L3：独立留出验收与支持范围

**可执行交付**：建立按题、页、书分组且无内容泄漏的开发/留出集；同题重复公式不能分到两边冒充泛化。冻结来源、人工盲标/复核记录、题型与版式分层、指标定义及接收门槛，再运行锁定版本；不同书、共享材料、复杂公式/图表和跨页均纳入计划。新发现失败回到开发集，改版后须使用未参与调参的验收材料。

**验收证据**：分别报告漏题/重复/切题边界、选项归属、公式符号和结构完整性、配答关系、未支持项及错误放行；给出分母、失败样例、人工介入范围与结果。模型置信度、两遍一致、MODEL_VISUAL 开发匹配和来源一致性不能当准确率。支持范围、可自动推进条件与拒绝条件由双方基于证据核准，数值门槛在验收前约定，不在看过结果后补设。

**外部依赖**：独立人工标注/复核者及可用于验收的未调参材料。由双方分批准备，先形成可复用的小批验收包，不要求 A 一次性标完整本书。

### L4：A/B 离线联调到人工最终提交

**可执行交付**：共同 SHA 下的可导入类型、统一校验器和固定消费者，真实 B 输出经过受控适配生成待执行计划；显式区分原始 fragments、文字/图片/表格呈现区、图内诊断、异常修订和版本回执。先离线模拟正常/异常/未知版本/陈旧来源/重复执行/回滚，再在用户授权范围内由 A 验证平台保存、读回和恢复。按定稿落实完整后逐题提交及人工最终确认，B 不直接接管平台执行。

**验收证据**：双方记录同一版本、输入/输出摘要、命令、合同兼容/迁移正负例；内容改动后旧检查失效，不把 READY 或 accepted 映射为业务 PASS。A 自行记录平台读回、框/角色/题序映射、异常恢复及接收结果；人工最终确认形成独立业务回执。只有离线联调通过时只声明离线范围，不声称在线能力已验证。

**外部依赖**：A 提供可执行合同/消费者和平台能力证据；来源印刷题号、导出 tixu 与平台身份须显式映射。A 状态当前仍为 `PENDING_A`，线上验证须另有用户授权。

### L5：可维护发布与持续改进

**可执行交付**：固定依赖/模型与来源版本、无隐式模型调用的缓存重放、安装和运行说明、迁移/回滚策略、支持范围及已知失败清单；记录每次识别、重试、缓存与人工修订的成本/耗时依据。模型/规则升级对同一冻结输入同时报告改善和退化，不覆盖旧运行。

**验收证据**：从干净导出和接收方环境重放、真实整书中断恢复、版本升级/降级与陈旧缓存拒绝；比较最终内容引用和审核依据。记录新增实际调用与缓存复用，模型调用、模型内部尺寸推理及费用各用明确口径；接收方完成安装、运行和异常路径复现并自行签收。

**外部依赖**：接收方运行环境、双方确认的 usage 字段与发布/支持安排。尚未测试的环境、平台能力或整书费用明确 UNKNOWN，不由局部运行外推。

## 近期推进顺序

1. 继续正文/公式的来源绑定补读，保留整行及原有候选，验证上标、根号、运算符和二维顺序；对开发参考的更正保留完整修订历史。补读所得不是自动正确答案，不按期望混拼模型输出。
2. 在已有显式草稿选择/修订、重建和当前重检上，继续验证复杂二维公式、混排、图表和共享材料的完整内容，建立独立人工核准及其失效规则，扩展“识别→发现风险→补读/修订→再组装/配答→当前质检”的整答/整书闭环；开发草稿能回放不代表内容质量已验收。
3. 并行补齐 19 条材料的题页/目录身份与整书来源清单；继续跨页真实负例，保留完整资产与前缀观察的范围区别。
4. 与 A 先对齐最小合同/固定消费者，同时冻结小批独立验收材料与指标；分批扩展至完整一本书、其他书/版式，再进行获授权的在线联调与人工业务验收。

## 完成判定与同步

每阶段都交付确切 SHA、输入/来源摘要、可执行命令、不可变结果、独立检查和未解决项；新增能力通过回归及可移植重放后更新 [B 状态](status/b.md)、说明和 evaluation，推送后核对远端版本。接收验证由 A 自行记录，B 不代签。

长期完成须逐阶段核对当前版本证据：整书范围和内容账本闭合；内容质量及错误放行门槛有独立验收；异常完成处理或明确转人工并记录；公共消费者和接收方联调通过；最终业务提交有人工确认。来源不全、仅开发参考匹配、候选仍未核准或 A 未验收时，目标继续进行，不因测试数量增长而提前关闭。
