## 为什么一直有交接和催材料

原A/B在不同工作树、数据格式和私有路径上推进；固定包只能证明某个局部输入可读取，不能补齐本机不存在的当前原件。章节来源未冻结时，又同时推进了难例、原型、合同和平台准备，容易出现“测试更多、包更多，但整章未闭合”。仓库历史文件记录各时点事实，A状态入口仍是模板，也使读者难以从一个页面判断最新进度。

接管后不再以等A作为默认动作：本端能继续读取来源、编写适配和保全代码、验证和发布；需要外部证据的项目则写出具体输入，不以重复模型复核或新增合成PASS代替。当前首要业务产出是可核验的完整清单及对应关系，其次是全量内容销账，再是实际保存/读回。
