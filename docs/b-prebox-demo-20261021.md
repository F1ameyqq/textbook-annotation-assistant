## 现在能做什么

导入一张或多张PNG/JPEG后，程序自动生成未核准的几何候选。在原图上可新建框、移动框、拖四角缩放、删除和撤销，也可改题干/选项/答案/解析/图形/表格等类型；数字坐标通过“应用坐标”一起提交。支持50%、100%、200%和适应宽度，坐标始终以原图像素存储，不随显示缩放改变。

保存草稿后可关闭重开；每次保存、图片导入、JSON导入和历史恢复都留下新版本。切页保留各页未保存编辑，“撤销”只作用于当前页最近50步本地操作；保存历史是整个工作区的快照，恢复历史会生成新版本。刷新/关闭前提示未保存内容，导出前要求先保存。

导出JSON携带原图Base64、SHA256、原图尺寸及所有框，可在另一台具有相同运行依赖的电脑上重新导入。JSON重导入的框统一标记IMPORTED_DRAFT，不能据导入记录冒称本地自动识别或人工核准；框坐标、类型和图片身份保留。

## 启动

在仓库根目录，用已有Python 3.11+运行；依赖为 `requirements-b.txt` 中的NumPy、Pillow和OpenCV。已有可用的opencv-python可复用。本工具不需要安装RapidOCR、公式模型、Node或DeepSeek；Node仅供坐标回归使用。

```powershell
# 首次打开空工作区，随后在页面选择书页图片
python -X utf8 tools/prebox_b.py --workspace data/runs/my-prebox

# 也可在启动时导入本机书页
python -X utf8 tools/prebox_b.py --workspace data/runs/my-prebox --images C:/books/page1.jpg C:/books/page2.jpg

# 关闭后重开同一个工作区，无须再次传图片
python -X utf8 tools/prebox_b.py --workspace data/runs/my-prebox
```

打开命令打印的 `http://127.0.0.1:端口`。默认随机本机端口，也可显式 `--port 58635`。只监听127.0.0.1，校验Host/Origin和修改请求令牌；不读取网站登录态、不上传图片、不执行网站动作。不要直接双击ui.html，它依赖本机工作区服务。

便携演示包见 [机器回执](../evaluation/book-46007447-prebox-demo-20261021.json)，内含代码、两张固定示例书页、启动文件、清单和重放脚本；启动前用仓库回执核对ZIP摘要。它不是带Python依赖的安装程序，不自动安装软件。

## 自动预框的依据与限制

复用 `annotation.recognition.baseline.legacy_backend()` 及既有 `tools/route_a_layout.py` 的分片、空沟、行投影、连通域和段落聚合。竖版双栏也尝试已有的受限空沟查找；过长段落按原图高度比例分成较短候选。记录后端和包装代码摘要，**不加载OCR、公式或付费模型**。

本轮固定书页 `assets/46007447_page_12.jpg` 和 `assets/46007447_page_14.jpg` 分别产生17和16个候选；文件名不是印刷页码映射，33个候选不是33道题。候选可能拆断共享标题、图形、表格或跨行题目，也可能包含页码、页眉等须人工忽略的区域。用户应按原图新增、调整、删除和分类；本演示不提供完整整题切分、自动配答或公式转写，不接入42题工作视图或A公共执行合同。

所有框均为DRAFT，工作区保持HOLD，human_verified=false，没有平台动作字段可供执行。调整自动框后来源改为MANUAL；MANUAL表示本地编辑，不表示人工验收。

## 坐标、来源与保存规则

- 坐标为 `[x0,y0,x1,y1]`，原图像素、右下半开；最小2×2。拖动保留尺寸并限制在原图内，反向拖画自动归一化，数字输入越界/非有限数拒绝。
- 页面ID由原始图片SHA确定。相同图片重复导入不覆盖已有人工编辑；同名但不同图片有不同身份，不按文件名套旧框。
- 导入或重开会检查来源字节；坏SHA、尺寸不符、重复页/框ID、未知版本或试图改成APPROVED均拒绝。JSON文本重复字段也拒绝。
- 图片只收单帧PNG/JPEG；带非1 EXIF旋转的图片须先转正另存，避免浏览器与原图坐标不一致。
- 每图25MB内、4000万像素内；每工作区最多100页、原图总量36MB、总框10000。容量限制用于保证导出的自包含JSON可再次导入；较大项目拆成多个工作区。
- SQLite事务保证保存失败不推进版本；陈旧页面返回冲突，保留其本地草稿。已写入但未发布的图片可能作为孤立文件保留，不计作已导入页，不借失败覆盖旧版本。
- 原图、工作区数据库、临时页面令牌放在本地运行目录，不提交仓库。导出JSON含完整图片，请按原材料的交付范围保管。
