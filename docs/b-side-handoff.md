## 1. 项目目标与边界

目标流程：选定书籍及范围 → 自动识别、组题配答、检查与录入 → 集中处理异常和抽查 → 人工最终提交。

- 正常题通过程序检查即可继续，不安排逐题人工批准。
- 跨页、组合题、公式、图表、七选五属于目标支持范围；尚未支持的情况明确输出异常。
- 优先采用 Python 模块化单体和文件产物，运行状态由 A 管理；不要求先拆微服务。
- 线上写入受明确书籍和操作范围约束；开发或登录成功不等于获得标注写入权限。
- A 侧后续写入测试书已由用户指定为 `46007447`《名校课堂八年级数学上册》，详见 [测试范围](coordination.md)。本书状态尚待独立采集，不能沿用旧样书的页映射、标注数量或验证结果。
- 详细语义见 [架构](architecture.md)、[合同草案](contracts-v1.md) 和 [模块开发计划](development-plan.md)。

## 3. 双方交换什么

以下描述接口合作关系，不是给 B 派单；B 的内部实现和推进顺序由 B 决定。

| 方向/范围 | 交换产物 | 消费方式 |
|---|---|---|
| A → B：来源 | `SourceBundle`、原图、目录、资源映射和历史参考质量标记 | B 可离线识别，无需平台账号 |
| B → A：识别 | `EvidenceBundle`、原图区域/裁片变换、内容证据和叠框预览 | A 展示证据、定位异常 |
| B → A：组题配答 | `QuestionGraph`、题目/片段关系、题答归属及不确定性 | A 生成平台计划 |
| B → A：内容检查 | `CheckReport(PRE_APPLY)`，含结构、配答和整页覆盖 | A 据结果推进、补救或分流 |
| A → B：平台限制与联调反馈 | 能力记录、政策、模拟结果、实际读回差异和可复现失败样例 | B 判断是否需要调整算法产物 |
| 双方：模型用量 | 调用、失败、重试、缓存与实际 usage 记录 | A 账本汇总；事件合同尚待实现 |

A 管理 source、delivery、runtime、exceptions 和 quality 的目标/平台后置检查；B 管理 recognition、assembly 和语义/覆盖前置检查。quality 只报告检查结果，重试和写入由 A 的运行流程执行。

算法产物保持平台中立：内容类型、题目角色和 Q/W/A/E 投影分开。浏览器、CSS 坐标和平台操作不进入 B 的通用语义接口。

## 5. 最容易误用的信息

1. **先确认原图身份。** 当前已核实样本的查看器页码/标注 `page_index=N` 对应资源 `page_{N-1}.jpg`；不能把该规则无条件套到所有书籍或同名 API 字段。
2. **通用框用原图坐标。** `bbox=[x1,y1,x2,y2]`，左上原点、像素单位、右下半开区间；同时绑定 `asset_id`、宽高和 SHA-256。裁片/缩放/补边保留可逆变换。
3. **历史坐标与平台屏幕坐标分开。** 正确配图后的历史框是原图尺度 1:1；实际浏览器 CSS 变换仍由 A 验证和适配。
4. **题号不能当主键。** `question_id/fragment_id/region_id` 是独立稳定身份；印刷题号会重置，`order_in_level` 是外部顺序属性。
5. **历史标注不是金标准。** 36 条框的 `verified` 均为 0，存在越界、跨类重叠；5 个 choice 框为多选项合框，与每选项独立框要求存在口径差异。
6. **宽图不是固定六栏答案表。** 它是多页扫描拼合，需识别子页/阅读顺序，分片后回投整张原图。
7. **覆盖检查要能发现漏掉的整题。** 只遍历已有候选、依赖题号连续或 OCR 自报置信度不足以放行。
8. **不要继续沿用旧结论。** `tools/page_mapping.py` 仍留有页 234 窄画布旧假设；`docs/solution.md` 的全局题序主键、全局 YOLO 格式和“导出不存在”已不适合作为新实现依据。

## 8. 接口变化与联调怎么交换信息

双方交接时提供最少信息：**代码/产物确切版本、合同版本、输入输出样例、复现方式、实际运行结果、已知限制**。B 可使用自己的任务管理方式，只需让交接产物可追溯。

字段不足或语义歧义先交换一个最小失败样例及修改建议，说明影响的生产者/消费者；双方确认后由 A 整合公共合同、样例和迁移说明。合同尚未固化时，试验输出应标为临时格式，不能各自宣称已冻结。

联调对齐共同合同与样例版本，并记录双方各自的确切代码/产物版本，分别记录合同兼容、模拟执行、真实平台读回三种结论。A 发现集成问题时反馈差异和复现证据，由 B 自主安排内部处理；不把 A 的兼容性反馈等同于 B 的内部验收结论。

模型成本交换实际调用量、失败/重试量、缓存和价格版本；尚未调用或尚未核算的部分直写“未测”。使用量事件格式及预算执行由双方接口约定解决，不在本交接文档许诺付费模型基准或日期。
