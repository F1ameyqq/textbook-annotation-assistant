## 运行入口与输入

只需要 Python 标准库。下列均为调用者自己的本地文件；输出含私有引用，放仓库外的全新目录。

```powershell
python tools/book_coverage_inventory.py --book-id BOOK_ID --page-inventory PRIVATE/page-inventory.json --directory-inventory PRIVATE/current-directory-inventory.json --image-manifest PRIVATE/image-manifest.json --mappings PRIVATE/source-mappings.json --out PRIVATE/new-coverage-run
python -B -m unittest discover -s tests -p test_book_coverage_inventory.py -v
```

`page-inventory` 采用已观察的原生页库存结构，逐页包含 `viewer_page`、`source_image_index`、`image_url`、`native_response`、`native_response_sha256`、`pre_annotation_blocks`，并绑定 `book_id` 和完整 `source_total_pages`。程序验证原始响应的 `code=0`、`data.file_id` 和单页 `data.pages`。不依赖一个通用 N−1 假设。

`image-manifest` 提供实际文件、字节数、SHA、原生 URL 和源图索引。`mappings` 的每个目录范围提供精确 `directory_id`、题页/答案页列表及逐页 `source_evidence`；可附原始 OCR 文件摘要与行索引。实际枚举条目放 `recognized_items`，每条绑定源页、源图 SHA、类型和证据种类；只有显式的完整枚举才生成该范围的题数，局部观察保持 `null`。`WORKED_EXAMPLE` 与题目/变式/阅读任务分开计数。

已有节点的 `native_bindings` 必须同时匹配原始节点 ID、当前 native order 和原父目录；所需新归属另列，不改输入文件。没有目录的真实来源范围放 `unbound_scopes`，不得伪造目录或题数。全部输入验证完成后才创建输出，已有目录拒绝覆盖。

本轮 14 项合成测试通过，覆盖零预标注误判、局部计数、例题分离、旧题序误标、错书/错页/篡改 SHA、OCR 源页错配和未绑定卷的空值约束。真实文件运行核查摘要见[机器记录](../evaluation/book-coverage-inventory-20261023.json)。这些完整性测试不证明内容转写准确。
