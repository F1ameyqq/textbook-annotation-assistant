# A30 普通材料入口：使用范围与操作

这是当前离线实现候选。`CUSTOMER_READY=false`；尚未完成真实新图片识别、首次安装、登录以及新平台生产验收。A29 已接受的九题运行包保持原状。

## 首次配置

本版本面向 Windows、Microsoft Edge 和 Python 3.12。首次双击 `SETUP_CUSTOMER.cmd`，安装 `requirements-customer.txt` 中的本地准备依赖及原生运行依赖。安装脚本没有在本次执行，安装成功尚未验证；失败时保留窗口错误和已有环境，不自动重新安装。以后统一双击 `START_CUSTOMER.cmd`。客户不需要编写 Python、JSON、清单、哈希或接受文件。

离线准备无需平台配置。需要平台功能时，在入口点击“首次配置”，新客户创建专用登录目录；已有本项目环境必须选原目录及原账本。随后点击“首次登录 / 登录失效”，由客户在可见 Edge 中完成登录。仅已有记录的指定证书例外可显式选择，默认保留正常证书校验。配置、登录及证书选择均未在本次执行。

任务与来源默认保存在 `%LOCALAPPDATA%\TextbookProduction`，与程序分开。升级程序时保留整个目录；不要删除账本、换登录目录或移除未知保存记录。

## 日常操作

1. 填写书籍编号、平台末级课时名称；按阅读顺序选择题目与答案材料，以及材料页范围。若计划使用原生题框，填写首张材料对应的书中页码。
2. 点击“准备材料”。TXT 可直接组题配答；新图片须明确勾选本地 OCR，已有当前缓存直接复用。程序保存来源、识别结果、候选和状态，无外部聊天 agent 参与。
3. 异常进入现有审校页。对照来源逐块编辑题干、选项、答案，再确认本题。缺材料、歧义或结构问题不能用确认按钮消除；补充正确范围后重新准备，成功识别结果复用。
4. “导出本地结果”生成 HTML 与 JSON。“启动生产”调用原生保存程序，逐题保存并以新子进程独立读回后再推进。成功项复用；未知保存停止该书后继。有完整原回执及释放证据时，“未知保存只读对账”只读取一次，不重新发送。

## 当前支持和限制

| 输入或步骤 | 当前实现 |
| --- | --- |
| UTF-8 TXT | 支持组题配答、本地审校和导出；分页使用换页符。文字预览坐标不能直接当原生题框。 |
| 单页 PNG/JPEG/WebP/BMP/TIFF | 支持导入、当前缓存消费、本地 RapidOCR 接口及 B 组题配答。真实识别尚未实测；所有扫描候选仍要求人工来源核对。 |
| 单栏、双栏 | 从现有 B 布局结果生成来源框；新增合成检查通过。不能由此保证任意版式。 |
| 普通文本原生插入 | 使用当前书籍/末级目录/来源页/全部旧题生成计划，无固定书号、题数、课时答案分支；只完成离线接线验证。 |
| 图形、富公式 | 保留待适配；发现图形引用或公式标记时阻断原生生产，不能用人工确认绕过。公式区域模型出口与原生图形正文尚未接通。 |
| PDF/DOCX、多页 TIFF、混合题答同页 | 尚不支持直接导入；当前要求分别提供单页图片或 UTF-8 TXT。 |
| 来源图片 | 原生生产要求与平台原书页字节及尺寸完全相同；扫描或二次压缩图片只能离线准备，当前没有几何配准。 |
| 平台保全 | 当前上限 128 个已有题，读取全部原生正文、分区和题框；不同题型、目录变化及未知字段不自动猜测。 |
| 未知保存 | 先对账；缺原回执、进程释放未证或已用过对账时停止，没有自动重试/清账入口。 |
| 导出 | 当前是本地 HTML/JSON 与读回记录，尚未接平台原生导出。 |

重复课时名称目前须在源码 API 使用完整目录路径，桌面选择器尚未接入目录选择，不能向客户宣称支持重名课时生产。现有 B 配答规则的语言/编号限制仍保留；未被识别的内容进入异常，不能自动升级为正确。

扫描题逐题确认、图形/公式出口、平台原生导出、首次安装和完整新平台链路仍是客户独立生产的缺口。开发者独立代码审查只在交付时进行，不是客户每次运行的依赖。
