# A30 普通材料入口：本机使用说明

双击交付目录中的 `START_CUSTOMER.cmd`。本机交付入口明确绑定已有工作区，任务、来源缓存、配置和保存账本继续使用原件。客户不需要编写 Python、JSON、哈希清单或向开发审查聊天提交材料。

当前真实完成范围、原生交付位置和客户就绪结论以交付目录中的最终验收说明为准。已有 A29 九题交付继续有效；A30 的新课时与它分别记录，不重新保存旧九题，也不宣称整章或整书完成。

## 从平台选择课时

1. 填书籍编号，点击“从平台选课时并准备”，在完整目录路径中选择末级课时。目录已有题框时，程序据此发现题页、答页并向后有界查找下一节标题；空目录可填写普通书中页范围。
2. 需要首次识别新页时，勾选本地 OCR。已经取得的原图与识别结果直接复用，不因为切换识别环境或重新打开任务再次识别。来源范围没有闭合、达到探查页数上限或出现失败时，状态会保留，不把已见题数当作整节题数。
3. 打开“异常审校”，对照整页核对题干、选项、答案及来源位置。点击“准备本课明确区域的公式候选”，程序一次准备尚未发送题目中的明确数学行；中文混排区域在各分区对照原图调整。检查候选后，可放入当前草稿选区，再保存并确认本题。题图、分栏、跨页和配答仍可能需要核对。
4. 点击“启动生产”，选择本次已经准备好的题目，再点击“保存所选题目并独立读回”。未选题及其异常继续留在同一任务中。每次保存后，程序以新进程取得当前状态，核对回执、正文、题框及旧内容保全后才推进下一题。
5. 所选范围完成后，程序取得平台原生导出，与独立读回内容逐项匹配，生成本地交付并自动检查显示。“导出本地结果”优先打开这份已有交付。只检查显示时，使用“本地显示复查”，不会因此再保存或重新向平台导出。

图形可以从程序提出的范围开始核对和调整，再绑定原图进入正文。公式候选会保留原始识别文字；明确放入草稿后仍可修正，也可以使用 `$...$` 或 `$$...$$` 编辑公式。交付由随包 MathJax 显示。本机公式功能以交付验收说明的启用状态为准，程序自动读取配套运行时；客户无需配置模型路径。识别结果、配对和布局仍需核对。

## 从本地普通材料准备

“准备材料”支持 UTF-8 TXT 和单页 PNG、JPEG、WebP、BMP、TIFF。选择题目、答案文件及材料页范围；若要生产原生题框，还需填写首张材料对应的书中页码。TXT 用换页符分页，文字预览坐标只用于本地准备。

平台生产要求来源图片与平台原书页的字节、尺寸一致。扫描件或二次压缩图片可以离线准备，当前不做几何配准。PDF、DOCX、多页 TIFF、混合题答同页尚不支持直接导入；本机 OCR 的实测范围也不代表任意版式都能正确识别。

## 状态和失败处理

成功保存直接复用。当前已存在的完整内容须同时匹配正文、公式、图片来源和题框后才记为复用；已有空题只在严格匹配原节点、原题框及当前空分区后填充内容。程序不会通过重建节点或移动旧题框来掩盖不一致。

失败、未知保存或无法证明释放时，保留原任务、专用登录目录、账本、日志和原始回执，该书后继停止。不要新建同题、清空状态或为了查找导出重发保存。“未知保存只读对账”先验证已有完整读回；没有保留读回时，只有原发送回执和进程释放证据完整才进行一次新读取。它不会重新发送保存。对账条件不满足或已经执行过时，保留原状态等待处理。

“继续准备”会先查缓存和原有操作记录。首次识别失败或结果未知时，不会用新模型名重试。来源缺失或归属不明的内容需要在正常审校界面补充，不能通过外部修改候选文件绕过。

## 本机环境与范围

本机入口引用已经准备好的 Python 3.12、Microsoft Edge 和本地识别依赖，不在每课运行时安装环境。Python 3.11 公式环境另行保留。工作区与专用登录目录均由既有配置绑定；升级程序保留它们，启动器找不到原工作区时直接停止，不回退到空任务列表。

当前完整旧题保全上限为 128 个已有题。目录、来源身份、未知字段或题型不能可靠处理时会停止；界面能打开、HTTP 成功、自动显示检查通过，都不能单独证明教材内容正确或整节完成。

迁移到另一台电脑需要一次性部署和客户自行登录，不能复制本机登录状态。本机包不等于已验证的跨机器安装包。开发者独立代码审查属于版本交付过程，不是客户每次选择课时、审校或生产的运行依赖。
