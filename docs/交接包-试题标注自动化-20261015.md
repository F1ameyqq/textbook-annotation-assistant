## 4. 技术路线（两路调查已收敛，一致）

推荐架构：**接口直调 + 离线视觉理解层**，识别、业务归并、执行三层分离。

- 底层版面/区域检测：[DocLayout-YOLO](https://github.com/opendatalab/DocLayout-YOLO)（可微调出 Q/W/A/E 角色）或 [RapidLayout](https://github.com/RapidAI/RapidLayout)（即开即用）；[MinerU](https://github.com/opendatalab/MinerU)、[surya](https://github.com/datalab-to/surya) 适合整书预处理。
- 题块切分 + 角色 + 配答（**无现成开源项目，自研核心**）：多模态模型，[dots.ocr](https://github.com/studio-dots-ai/dots.ocr) 可作 baseline。
- 公式：[Pix2Text](https://github.com/breezedeus/Pix2Text)、[LaTeX-OCR](https://github.com/lukas-blecher/LaTeX-OCR)；表格：[CascadeTabNet](https://github.com/DevashishPrasad/CascadeTabNet)；OCR 基线：RapidOCR。
- 坐标分层：原图像素为主坐标空间；六栏答案图按内容分栏出裁片，记录偏移/缩放/补边，裁片坐标回投原图去重；浏览器画框再套画布 client 映射（`client = origin + offset + scale × original`），不得混用。
- 一题多物理片段；中间结构保留：题目身份、来源、片段、逻辑关系、内容、异常、执行回执、调用记录。
- 评测口径：漏题/重题、题干选项完整性、答案解析归属、目录与题号重置、图表公式保真、跨页完整性、人工修正比例；成本 = 全部调用费用 / 人工验收通过题数（失败跳过计入分子）。IoU、JSON 可解析率不能单独代表成功。
