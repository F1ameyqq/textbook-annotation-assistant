## 使用者现在可以完成的流程

启动本机服务后，在同一界面按完整章节、题号、正文或答案 ID 查找答案，对照原始 OCR、原图裁片、当前正文/解析及公式显示，查看关联问题和全部问题队列。66 个答案候选全部可导航；同章同号和不同章同号保留独立身份。反思 Q9 可查看两个不同来源资产及五个图形，没有用资源数字 173 合并页身份。

使用者可以编辑已有来源区域的 plain/LaTeX 文字段，增删、调整顺序；也可以显式改写一个原片段的完整文字，或选定已有模型候选替换原文字选区。候选选区使用原片段的 Unicode 码点，和当前编辑文字、JavaScript UTF-16 位置分开；混排片段未触碰时不会自动转成单一格式。区域的来源几何及原片段分配保持固定；此版本没有新增/重画区域的交互。

保存只发送当前答案实际改变的块，生成新计划、当前正文/解析、呈现和质检，并运行已有独立投影审计。支持撤销未保存编辑、将历史操作恢复为新版本、重新加载及导出当前计划。切换答案、刷新和恢复前会处理未保存草稿；陈旧页面的 expected_head 被拒绝，错误不会显示为保存成功。未知数学语法保留整条原 LaTeX，支持的 MathML 只作语法显示。

作者类别为 MODEL_DRAFT、HUMAN_DRAFT 或 SYNTHETIC_TEST，任何类别都不签发内容核准。作者只记录本次快照编辑者，不能代表已核对全部继承操作。此次真实界面操作使用 MODEL_DRAFT；所有输出始终 HOLD、complete=false、transcription_verified=false、business_acceptance=false、platform_actions=[]。
