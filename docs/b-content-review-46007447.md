## 使用者现在可以完成的流程

启动本机服务后，在同一界面按完整章节、题号、正文或答案 ID 查找答案，对照原始 OCR、原图裁片、当前正文/解析及公式显示，查看关联问题和全部问题队列。66 个答案候选全部可导航；同章同号和不同章同号保留独立身份。反思 Q9 可查看两个不同来源资产及五个图形，没有用资源数字 173 合并页身份。

使用者可以编辑已有来源区域的 plain/LaTeX 文字段，增删、调整顺序；也可以显式改写一个原片段的完整文字，或选定已有模型候选替换原文字选区。候选选区使用原片段的 Unicode 码点，和当前编辑文字、JavaScript UTF-16 位置分开；混排片段未触碰时不会自动转成单一格式。区域的来源几何及原片段分配保持固定；此版本没有新增/重画区域的交互。

保存只发送当前答案实际改变的块，生成新计划、当前正文/解析、呈现和质检，并运行已有独立投影审计。支持撤销未保存编辑、将历史操作恢复为新版本、重新加载及导出当前计划。切换答案、刷新和恢复前会处理未保存草稿；陈旧页面的 expected_head 被拒绝，错误不会显示为保存成功。未知数学语法保留整条原 LaTeX，支持的 MathML 只作语法显示。

作者类别为 MODEL_DRAFT、HUMAN_DRAFT 或 SYNTHETIC_TEST，任何类别都不签发内容核准。作者只记录本次快照编辑者，不能代表已核对全部继承操作。此次真实界面操作使用 MODEL_DRAFT；所有输出始终 HOLD、complete=false、transcription_verified=false、business_acceptance=false、platform_actions=[]。

## 启动和输入

```text
python tools/review_content_b.py --evidence CURRENT_E.json --graph CURRENT_G05.json --base-check CURRENT_CHECK05.json --review CURRENT_REVIEW.json --plan INITIAL_PLAN.json --source LOCAL_SOURCE.json --source ADJACENT_SOURCE.json --workdir data/runs/my-content-review
```

输入为现有行内链生成的 plain E/G05/Check05、对应派生审核及显式初始计划。可以使用已校验的 `content-revision-inputs.zip` 固定派生对象作开发重放；该包不含完整原图或人工标准。当前真实初始计划为 `tests/fixtures/book46007447/content-region-plan-v1.json`（内部 revision=3）。原图 manifest 使用既有 `b-source-trial/0.1`，按相对 path 定位原图；可以重复 `--source` 覆盖当前 E 的六个资产，同资产不能重复。缺少或改变原图时拒绝启动/读图/保存，不能以固定裁片代替全页来源验证。

命令输出实际 `http://127.0.0.1:PORT`，在本机浏览器打开即可；默认随机可用端口，或传 `--port`。`--check-only` 初始化和审核工作区后退出，不开启 HTTP。服务不连接标注网站、不使用登录态、不运行 OCR/公式模型。界面和字体无外部依赖；仅监听 loopback，校验 Host、Origin 和页面临时令牌，无任意文件读取入口或跨域许可。工作区、原图副本和临时令牌不提交仓库。

已有工作区须以完全相同的五个初始对象、来源身份和兼容实现重开；初始计划不是上次导出的当前计划。原图路径可以移动，但 asset ID、SHA、尺寸及输入身份须相同。升级或更换运行依赖时当前版本要求新工作区，不能直接接受旧投影。

## 保存、故障和已有流水线

工作区将五个输入及原图字节冻结为内容寻址物件，并持续检查实际源图。SQLite 保存当前 head、完整版本、attempt 和事件；提交前复查源图及刚发布物件。事务失败不推进 head，保留失败记录和孤立物件；重启逐版审核已提交历史，不消费孤立文件。测试覆盖异常抛出和静默损坏已发布对象两个提交窗口。

没有新增流水线阶段或修改旧内容 schema。导出的是现有完整 ContentRevisionPlan；单片段计划沿用0.1/G06，区域计划沿用0.2/G07。后续继续通过 `tools/run_pipeline_b.py --content-revision EXPORTED_PLAN.json` 消费，并结合相同来源、审核及既有回补/续接/inline 参数。内容变化不能借用旧检查，最终按新的 E/G/check 引用交接。

本机 UI 状态/API 是 B 内部 `b-content-review-*-trial/0.1`，不是 A 的公共合同。A 仍消费显式计划、当前图谱/检查及适配后的共同版本，不依赖本机端口、令牌、数据库路径或 UI head 的跨环境相同。
