## 四、分区与提交规则（拟）

1. **书级分区**：会话 A 只碰书 A，会话 B 只碰书 B；不跨书切换。
2. **题级分区**：同书并行时，按 order 区间切（如 A 做 1–7，B 做 8–14），**绝不同题**。
3. **提交串行**：即便并行画框/识别，`提交修改` 采用队列串行下发（避免"指针滞后"跨会话串扰——虽然是推断，但代价太低）。
4. **每步闸门**：
   - 识别后 `results[].question_order` 必须全等于预期
   - 提交响应 `inserted` 与预期一致
   - 提交后立即按 order 回读
5. **失败即停**：任一会话闸门失败 → 该会话中止，不影响另一会话，但需人工确认后再继续。
