# 试题版面测量助手 · 使用手册

> 版本 v1.0 ｜ 适用：Windows 10/11 ｜ 不需要联网登录，不需要装任何软件（用打包的 Python）

---

## 1. 这个工具是干什么的

把教辅书的一页扫描图，自动切出**每道题在页面上的位置**，并画成一张带编号的确认图。

**为什么要它**：以前人工量一页的题目位置大约 **15 分钟**；现在点两下、等 1 分钟。

**它不做什么**（避免误会）：
- 不登录平台、不改平台数据、不上传任何东西
- 不替你画框、不替你提交（那一步还是人工操作平台上原有的流程）

---

## 2. 第一次使用：复制文件夹

把整个 `试题标注助手` 文件夹复制到电脑任意位置（**不要只复制 .bat 文件**，其他文件是它的零件）。

检查这三样在不在：

```
试题标注助手\
  02_启动.bat        ← 你点的就是它
  run_measure.py
  config.json
  tools\
```

小提示：文件夹名和路径里**可以有中文**（已专门处理过）。

---

## 3. 每天怎么用（4 步）

**第 1 步**：双击 `02_启动.bat`
会弹出一个黑窗口，这是正常工作界面，别关。

**第 2 步**：输入题目页码
```
请输入要测量的【题目页码】，例如 28-30 或 28,29,31
题目页码：28-30
```
- 连续几页写 `28-30`
- 不连续写 `28,29,31`

**第 3 步**：输入答案页码（可以跳过）
```
如果有【答案页码】请一并输入（例如 174-176），没有就直接回车跳过
答案页码：174
```
不知道答案页码？直接按回车。答案页可以之后单独跑。

**第 4 步**：等结果
每页大约 **20–60 秒**（慢在这台电脑的 OCR 识别），跑完窗口会提示"完成"，按任意键关闭。

## 4. 结果在哪里看

打开 `试题标注助手\报告\` 目录：

| 文件 | 是什么 |
|---|---|
| `汇总.md` | **先看这个**：每页测出几道题、哪几题要复核 |
| `汇总.csv` | 同上，可以用 Excel 打开 |
| `第28页_题目.png` | **确认图**：原图上画了每道题的框和编号 |
| `第174页_答案.png` | 答案页的行带图（见第 6 节） |
| `_源图\` | 下载下来的原图缓存，可删 |

### 确认图怎么看

- **红色框 + 白底编号 `Q1`…`Q14`** = 自动定位，可信
- **橙色框** = 脚本按版面结构推断出来的，**请重点看这几道**
- 框的位置不对 → 不用自己改，把问题记下来（见第 7 节）

## 5. 三种状态怎么理解

`汇总.md` 里每页有一个"状态"：

| 状态 | 含义 | 你要做什么 |
|---|---|---|
| 成功 | 题号都自动识别出来了 | 扫一眼确认图即可 |
| 需人工 | 这页没有可识别的题号（常见于**上一页题目的续页**、或"变式/阅读思考"那种整块内容） | 打开行带图，人工确定范围 |
| 失败 | 图片下载失败或页码不存在 | 检查页码是否写错 |

> 续页类页面（如第 30 页）本身就没有 `1. 2. 3.` 这样的题号，工具会输出 **行带图**（每行标 R1、R2…），
> 你在图上指出"这块属于第几题"即可，不需要工具猜。

---

## 6. 答案页为什么只给"行带"

答案册一页里常常横跨好几个课时，题号在页内会**重复出现**（例如 `1.A 2.D 3.24 … 1.C 2.D 3.0`）。
整页硬切必然错位，所以工具只把每一行标出来（R1、R2…），
你告诉它"第 2 课时是 R12 到 R20"，它就能精确切。

---

## 7. 有问题怎么反馈（很重要）

**不需要你会改代码**。发现框不对，回一句话就行，格式：

```
第28页 第3题 框偏上了
第29页 第7题 框太宽，把选项也框进去了
第30页 应该是 13、14 两题，工具没识别出来
```

一句话 + 页码 + 题号，我们就能定位修改。

## 8. 常见问题

**Q：黑窗口一闪就没了？**
A：说明 Python 没找到。确认 `便携Python\python.exe` 或系统 Python 存在；把窗口里最后一句报错发给我们。

**Q：提示"图片读取失败"？**
A：多半是页码写错了（这本书题目页从第 1 页开始，答案页在 149 页之后）。换个页码再试。

**Q：跑得很慢？**
A：OCR 是纯 CPU 的，一页 20–60 秒正常。机器忙的时候更慢，可以晚上批量跑。

**Q：能不能不点黑窗口，直接拖文件进去？**
A：可以，但需要技术同事配一下，默认不开启。

**Q：数据安全吗？**
A：全程只做两件事：从平台图床下载原图、在本机算位置。**不登录、不写平台、不上传**。
token、账号密码都不碰。

## 附：技术同事看的

- Python 3.11 + `opencv-python` + `numpy` + `rapidocr_onnxruntime`（纯 CPU，模型随包）
- 源图直链：`{oss_base}/{book_id}/{book_id}_page_{平台页码-1}.jpg`
- 版面算法：墨迹投影切栏 → 行投影 → OCR 题号锚点 → 齐栏补号（详见仓库 `tools/page_measure.py`）
- 换书：改 `config.json` 里的 `book_id`
