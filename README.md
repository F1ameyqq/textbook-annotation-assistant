# 教材试题标注自动化助手 · 实验台

把中文教辅扫描页面自动切成 **题干（Q）/ 每个选项独立框（W）/ 答案（A）/ 解析（E）** 四类区域，
并与题号（含目录与课时层级）配对，用于「自动框选 + 配答 + 人工确认提交」。

> 本仓库是**实验与证据仓库**：记录可行的技术路线、实测数字、失败案例与边界。
> 线上平台的写操作（建框/改目录/提交审核）不在本项目承诺范围内，本项目**只做读取与离线识别**。

## 2. 已实测确认的事实（都可复现）

### 2.1 环境

- Python 3.11 + `torch 2.11.0+cu128`、`opencv`、`paddleocr 3.7`、`rapidocr-onnxruntime 1.4.4`、`easyocr`、`onnxruntime 1.25`
- GPU：RTX 5060 Laptop **8GB**，算力 `sm_120`（Blackwell），`torch.cuda.get_arch_list()` 含 `sm_120`，bf16 正常
- **OSS 页图可匿名直读**，不需要浏览器会话参与 → Phase 1 拉样图零会话成本

页图 URL 规则（实测可用）：

```
https://oss-ef-bd-2026-gz.oss-cn-guangzhou.aliyuncs.com/upload_images/{file_id}/{file_id}_page_{索引}.jpg
```

### 2.2 版面结构（重要纠正）

交接材料称第 234 页是「3467×1615 六栏答案图」。**实测不是。**

| 页(0基索引) | 尺寸 | 墨迹% | 内部纵向空白沟 | 结论 | 历史标注数 |
|---|---|---|---|---|---|
| 7 | 1178×1673 | 2.48 | 0 | 单一页扫描 | 0 |
| 8 | 1176×1681 | 1.21 | 0 | 单一页扫描 | 12 |
| 9 | 1179×1671 | 1.74 | 0 | 单一页扫描 | 7 |
| 10 | 1175×1674 | 1.10 | 0 | 单一页扫描 | 2 |
| 233 | 3467×1615 | 1.88 | 5 | **多页扫描拼合** | 0 |
| 234 | 3465×1615 | 2.68 | 3 | **多页扫描拼合** | 15 |

判定方法（`tools/layout_probe.py`）：找**贯穿式**空白沟——某一列（行）在垂直方向上的
最长连续空白达到该方向总长的 70%（`span_frac=0.7`）且宽度 ≥12px（`min_run=12`）。
该阈值下页 7/8/9/10 无内部纵向沟，页 233/234 分别有 5 条 / 3 条。

> 用 `min_run=4` 会把「文字行间的窄空列」误判成沟，曾导致页 8/10 被错判为拼合版面，已修正。

**影响**：路线里原计划的「六栏答案图按内容分栏出裁片」需要重写为「按内部纵向沟切出子页」。

### 2.3 坐标系不一致（最大风险）

页 234 的 15 个历史框，`x` 只用到 `0–594`、`y` 只用到 `254–1164`，而这页图是 3465×1615
（框只占图宽的 **17.2%**）。逐一检验后：

| 假设 | 墨迹覆盖率均值 | 结论 |
|---|---|---|
| 原坐标直接用 | 2.832% | 框未框住文字 |
| 按 `3465/594≈5.8333` 缩放 | 0.330% | 更低 → **否定** |
| 平移 +71（第一内容栏起点） | 2.828% | 无改善 → **否定** |
| 平移 +1100 | 1.953% | 无改善 → **否定** |

**结论：页 234 的历史框与下载到的这张图之间，不存在可离线复原的简单平移-缩放关系，
不能当坐标真值使用。** 同页另有 2 处跨类重叠（analysis ∩ answer 占较小框 91.1% / 100%）。

页 8 存在 `x2=1181.09` 而图宽仅 `1176` 的框（**超 5.09px**）——交接材料记的「超 3.09px」有误。
这说明平台记录画布可能比 OSS 下载图更宽，是坐标标定的关键线索。

### 2.4 口径警告

历史 `choice` 全是 **4 个选项合 1 框**，而业务口径要求**每选项独立一框**。
因此历史 choice 框**不能**直接当选项级真值用于评测。

## 3. 目录结构

```
data/raw/images/          6 张样图（OSS 原始下载，未改动）

data/raw/api_evidence/    接口响应证据（已脱敏：requestHeaders 整块移除）

docs/                     方案、评测口径、踩坑记录
```

## 4. 如何复现

```powershell
# 1) 拉页图 + 读历史标注（只读线上，零写入）
python tools/land_data.py

# 2) 版面结构 + 坐标系完整性校验，生成报告与证据图
python tools/verify_data.py

# 3) 构建"可公开"的脱敏发布包（会做凭证复检）
python tools/build_release.py --target _release
```

依赖：`numpy`、`Pillow`、`requests`；OCR 路线另需 `rapidocr-onnxruntime` 或 `paddleocr`。

## 5. 安全约定

- **不提取、不记录平台令牌与账号密码。** 一切线上访问经由用户已登录的浏览器会话。
- `data/raw/api_evidence/*.redacted.json` 已移除 `requestHeaders`（原文件含明文会话 JWT）。
  原始响应只保留在私有工作区，**不进入本仓库**。
- 本项目**不接**平台的提交/送审/识别并提交接口。
