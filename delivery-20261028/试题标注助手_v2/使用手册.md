# 试题标注助手 · 使用手册

> 版本 v2.0 ｜ Windows 10/11 ｜ 客户操作手册（不需要懂代码）

---

## 这套工具是干什么的

把教材扫描页变成「题目框坐标」，再自动在标注平台上画框、识别、提交。

**能省多少时间**：人工量一页（10 题）约 20 分钟；用本工具 **6–8 分钟/页**。

**分工**：机器做像素计算和点击，**人做"哪几行属于哪道题"的判断**——这一步机器替不了，
所以流程里有一处必须人看图确认。

---

## 一、第一次使用（约 20 分钟）

### 1. 检查环境

双击 **`1_安装.bat`**，它会逐项检查：

| 项 | 需要什么 | 缺了会怎样 |
|---|---|---|
| Python 3.11 | 必需（出图/预览/坐标计算） | 提示你装，或把便携版放到 `便携PY\` |
| numpy / Pillow / opencv | 必需（Python 库） | 自动联网安装（约 60MB） |
| Node.js 18+ | 只有"提交"需要 | 出图、预览照常可用 |
| ego lite | 只有"提交"需要 | 可跳过，之后再装 |

### 2. 填书号

安装脚本会生成 `app\config.json`，用记事本打开，把

```json
"fileId": "46007447"
```

改成你的书号（平台上能看到）。同时把 `"dirNode"` 留着，提交时会被覆盖成你选的课时。

### 3. 装 ego lite（可选，提交时才需要）

在 `1_安装.bat` 提示时输入 `ego-*.crx3` 安装包的完整路径。
脚本会自动解开安装，**无需运行官方安装器**。

### 4. 首次登录（只有一次）

双击 **`2_自检.bat`**，它会打开浏览器：

1. 若出现「您的连接不是私密连接」→ 点 **高级 → 继续前往**
2. 用你的标注账号**登录**
3. 回到命令行，看到 `CHECK_ENV_OK` 即成功

> 这一步之后登录态会记住，除非换电脑或 token 过期，不用重复。

## 二、每天的流程（5 步）

### 第 1 步 · 出图（`3_出图.bat`）

输入页码，支持三种写法：`35` / `35,36` / `35-37`

产出：
- `报告\p35_rows.png` —— **行号图**（每行标了 `L00` `L01` … `R00` …）
- `specs\p35_qspec.json` —— 空白模板

### 第 2 步 · 填行归属（核心，需要人看图）

打开 `报告\p35_rows.png`，看清楚"第 1 题占哪几行"，然后在
`specs\p35_qspec.json` 里写：

```json
"items": [
  {"n": 1, "stem": ["L05-L09"]},                     ← 第1题：左栏第5到第9行
  {"n": 2, "stem": ["L10"], "opt": ["L11","L12","L13","L14"]},   ← 选择题：4个选项各占一行
  {"n": 4, "stem": ["L20-L21"], "opt": ["L22x4"]}    ← 一行内横排4个选项
]
```

三种写法：
- `L05-L09`：左栏第 5~9 行合并成一个题干框
- `L11`：单独一行
- `L22x4`：这一行**横向切成 4 个框**（一行四个选项时用）

> 不确定就先填个大概，下一步看图修正——**这一步允许来回改**。

### 第 3 步 · 预览（`4_预览.bat`）

输入 `p35_qspec`，产出 `报告\p35_overlay.png`：

- **红框** = 题干框
- **绿框** = 选项框

**逐个核对**：每个红框是不是圈住一道完整题干？绿框是不是各自圈住一个选项？有没有框到隔壁题？
不对就回到第 2 步改行号，直到全对。**这一步不许跳过**。

### 第 4 步 · 演练（`5_提交.bat` 选 1）

DRY RUN：只检查结构（几题、几框、类型），**不写任何数据**。
看到 `CHECK_CLEAN` 且逐题数量正确才继续。

### 第 5 步 · 真提交（`5_提交.bat` 选 2）

输入 `YES` 确认后执行。每题会：选课时 → 翻页 → 画框 → 选题型 → 识别 → 提交 → 回读对账。
结果在 `%TEMP%\submit.txt`。

> ⚠ **同一本书同一时间只能有一个人在提交**。两路同时提交会撞题号
> （实测会把两道不同课时的题合并成一道）。

## 三、出问题了怎么办

| 现象 | 原因 | 处理 |
|---|---|---|
| `CHECK_ENV_FAIL not found: 选择书籍` | ego 停在首页，没进标注页 | 重新跑 `2_自检.bat` |
| `net::ERR_CERT_DATE_INVALID` | 平台证书过期 | 在 ego 窗口点「高级 → 继续前往」 |
| 框整体偏一行 | `stem` 行号填错 | 回第 2 步改行号 |
| `CHECK_WARN` 有警告 | 几何自检发现问题（空框/跨题重叠） | 别提交，先改 spec |
| 提交后题号错位 | 选错了课时目录 | 用 `app\cleanup_orders.mjs` 删掉重来（**会影响后续题号**） |
| 提示"找不到 ego-browser" | ego 没装或没进 PATH | 重跑 `1_安装.bat` 第 4 步 |

## 四、重要约束（血泪教训）

1. **单写者**：一本书同时只能一个人提交。要并行请按课时分工，且各写不同课时。
2. **删题会重排题号**：删中间任何一题，后面全部前移。删除前先确认没人在同时作业。
3. **dry run 通过 ≠ 框是对的**：dry run 只验结构，位置必须靠 overlay 图人眼看。
4. **别升级 ego**：本工具按 0.6.1.13 验证；升级可能改变行为。

```
  1_安装.bat  2_自检.bat  3_出图.bat  4_预览.bat  5_提交.bat
  app\            工具本体（不要改）
  specs\          spec 文件（你要编辑的）

  源图\           自动下载的页图
  报告\           行号图 / 验收图 / 结果
  便携PY\         （可选）放便携版 Python
  便携NODE\       （可选）放便携版 Node
```
